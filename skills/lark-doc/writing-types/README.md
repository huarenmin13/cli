# 飞书写作类型 · 路由索引

飞书在线文档的垂类写作类型都在本目录，每个一份自包含 guide（写作 + 该类型的飞书格式差量）。
**路由方式**：识别用户要写的写作类型（中文）→ 在下表查到英文文件名 → 读 `writing-types/<文件>` 取写作知识。文件名用英文 slug（工程稳、跨平台不乱码）；中文类型名在此表和每个文件顶部的头注里。

> 公文/简历/专利/签证等 Word 类型不在本目录，走 `office-word`（见顶层 `SKILL.md`）。

| 写作类型（中文） | 文件 | 触发场景关键词 |
|---|---|---|
| 影评 | `film-critic.md` | 电影/影片/片段评论、影评 |
| 种草文案 | `product-seeding-copywriting.md` | 种草、带货、小红书笔记、产品安利、转化文案 |

新增写作类型：往本目录加一份 `<英文slug>.md`（含头注 + 飞书格式差量），并在本表加一行；范文放 `samples/`。
