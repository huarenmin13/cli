# Brand Copywriting Document

品牌文案文档生成 Skill，用于创建、改写、优化和编辑品牌传播类文档。

当用户需要创建、改写、优化或编辑品牌文案类文档时，使用本 skill。适用于品牌文案、广告文案、产品宣传文案、Slogan 方案、主视觉文案、品牌宣言、企业使命、服务说明、功能说明、社交媒体种草文案、品牌大片旁白、广告创意方案等文档内容生成。重点是生成自然、清楚、具体、有品牌质感、符合传播场景、可直接放入文档的内容。不适用于纯文学创作、学术论文、普通公文、新闻报道和非商业目的随笔，除非用户明确要求改成品牌传播或广告宣传表达。

核心目标不是写几句漂亮话，而是生成一份结构清楚、内容可用、品牌调性明确、适合继续编辑和排版的文档内容。

---

## 适用场景

当用户提出以下需求时，触发本 Skill：

- 创建品牌文案类文档，例如品牌文案方案、广告文案方案、Slogan 方案、主视觉文案方案。
- 创建产品宣传文档，例如产品卖点页、产品系列介绍、详情页文案、种草文案方案。
- 创建品牌表达文档，例如品牌介绍、品牌宣言、企业使命、企业愿景、品牌故事。
- 创建服务说明文档，例如服务介绍、功能说明、使用建议、预约页说明、客服话术。
- 创建传播内容文档，例如海报文案、社交媒体文案、品牌大片旁白、TVC 文案。
- 优化已有文档，使其更自然、更高级、更有品牌调性、更像专业广告文案。
- 基于用户提供的已有文案、品牌资料、产品资料、竞品资料，整理成一份可编辑文档。

不适用以下场景：

- 用户只是要求翻译普通文本，且没有品牌传播目的。
- 用户要求写学术论文、教学设计、公文、新闻稿，且没有广告或品牌表达需求。
- 用户要求做纯信息总结、资料整理、表格分析。
- 用户要求写小说、诗歌、散文，且没有商业传播目的。

## 核心原则

好文案应当自然、真诚、有用、说人话，像真人写的。文采不是堆形容词，而是用词准确、表达克制、有节奏、有力量。

广告文案除了清楚、有用，还要有品牌质感。品牌质感来自稳定的品牌气质、独特的品牌符号、准确的用户欲望、可想象的画面、克制的表达和能被记住的创意主张。

不要把所有广告都写成说明书。服务说明要清楚，产品卖点要具体，品牌广告要有气质，奢侈品和审美类品牌要有留白、画面和向往感。

需要避免的典型问题：

- 辞藻堆砌但不知所云。
- 对仗工整但像模板。
- 高高在上但没有信息量。
- 每个候选只是换几个词。
- 品牌自嗨但用户看不懂。
- 用“极致、奢华、传奇、尊贵、赋能、矩阵、全链路”等词制造伪高级感。
- 写出任何品牌都能用的通用文案。
- 为了“说人话”把广告写成大白话说明文。
- 为了“有文采”把文案写得难懂、虚浮、离用户很远。

## 任务分类

先判断用户需求属于哪一类，再选择对应的文档结构和处理重点。

| 用户需求 | 任务类型 | 处理重点 |
|---|---|---|
| 产品卖点、详情页、电商主图、种草文案| 产品营销类 | 产品作用、用户问题、使用场景、差异化、购买理由 |
| 品牌广告、品牌大片、品牌态度、品牌故事 | 品牌形象类 | 品牌气质、审美、欲望、世界观、长期心智 |
| Slogan、标题、主题句、主视觉文案 | 短句主张类 | 短、准、清楚、有记忆点、能放在视觉中心 |
| 企业使命、愿景、品牌宣言、价值主张 | 企业表达类 | 我们是谁、做什么、长期为谁创造什么价值 |
| 服务流程、功能介绍、使用建议、客服话术 | 说明转化类 | 这是什么、谁适合用、怎么用、有什么帮助 |
| 评估、改写、去 AI 味、改成某品牌调性 | 文案优化类 | 找出问题，按品牌气质、场景和用户需求重写 |
| 创建完整文档、方案文档、品牌文案稿 | 文档生成类 | 结构完整、标题清楚、内容可编辑、便于继续排版 |

## 工作流程

### 1. 判断真实需求

结合用户最后的指令和上下文，判断用户真正想要的是创建文档、生成文案、改写文案、优化已有文档、评估问题，还是做多版本方案。

同时判断核心目标：

- 卖具体产品：重点是产品作用、用户问题、使用场景、差异化和购买理由。
- 推抽象品牌：重点是品牌是谁、相信什么、长期为谁创造价值。
- 表达个人感想或价值观：重点是真实、自然、有态度，不要硬营销，不要过度上价值。
- 创建文档：重点是结构清楚、层级明确、内容完整、便于继续编辑。

### 2. 判断内容方向

根据任务判断文案方向：营销向、内容向、说明向或品牌形象向。

- 营销向：突出产品卖点、用户利益、差异化、购买理由、认知建立。
- 内容向：突出情绪共鸣、生活场景、品牌态度、价值观表达。
- 说明向：讲清楚这是什么、怎么用、适合谁、有什么帮助。
- 品牌形象向：突出品牌气质、审美、欲望、世界观、记忆点和长期心智。

### 3. 识别品牌气质

写文案前，先判断品牌应该用什么语气说话。不要所有品牌都用同一种“高级感”。

需要判断：

- 品牌是大众消费还是高端品牌。
- 品牌是亲近还是克制。
- 品牌是功能驱动还是审美驱动。
- 品牌是年轻活泼还是经典稳重。
- 品牌是理性专业还是感性浪漫。
- 品牌是要制造购买冲动，还是建立长期向往。
- 品牌适合直接讲利益，还是适合用画面、象征和留白。

文案必须符合品牌气质。不能把奢侈品牌写成促销种草，不能把大众品牌写成高冷宣言，不能把科技品牌写成空泛抒情，不能把工业品牌写成生活方式广告，不能把年轻品牌写得像传统公关稿。

### 4. 提取品牌资产

写作前提取品牌可使用的独特资产，避免写出任何品牌都能用的文案。

可提取的品牌资产包括：

- 品牌历史、创始人精神、经典产品。
- 标志性颜色、材质、设计、场景、动作、人群。
- 标志性语气、长期价值观、品牌和用户之间最稳定的关系。

如果用户没有提供完整信息，可以根据已有信息做合理判断，但不要编造具体事实。文案应尽量围绕品牌自己的资产展开，而不是使用通用形容词。

### 5. 按品类调整写法

不同品类不能使用同一套广告语言。

- 奢侈品：重点是稀缺、时间、手工、审美、距离感、传承、欲望和身份感，不要写成促销或功能说明。
- 美妆香水：重点是气味、肤感、光泽、亲密关系、自我状态、身体感受和情绪氛围，不要只写成分。
- 时装配饰：重点是风格、姿态、场合、材质、剪裁、身份表达和穿戴者状态，不要只写“好看”“高级”。
- 汽车：重点是安全感、掌控感、驾驶情绪、家庭关系、身份表达和路上场景，不要只堆配置。
- 科技产品：重点是效率、创造力、少一步操作、少一点等待、让复杂变简单，不要堆技术黑话。
- 食品饮料：重点是口感、气味、温度、当下满足和具体食用场景。
- 家居家电：重点是日常便利、舒适感、家庭关系、空间体验和长期使用中的省心。
- B2B / 工业：重点是稳定、可靠、风险降低、效率提升、长期成本和专业信任，不要写成空泛抒情。

### 6. 提炼广告创意主张

在正式写文案前，先确定这次广告最想让用户记住的一件事。

广告创意主张要回答：

- 这次传播的核心观点是什么。
- 用户看完后应该如何重新理解这个产品或品牌。
- 这句话背后有没有情绪、场景、冲突、隐喻、反差或独特视角。

不要把广告写成卖点罗列。好的广告应该有一个清楚的创意核，可以是一个具体场景、一个用户矛盾、一个品牌态度、一个产品细节、一个反差，或一个能被记住的画面。

### 7. 设计用户欲望

不要只写“这个产品有什么用”，还要判断用户为什么会想拥有它。

普通消费品可以重点写解决问题、提升效率、降低成本、带来方便。高端品牌、审美品牌、香水、美妆、时装、珠宝、汽车等，需要同时写出身份感、审美感、仪式感、情绪价值、生活方式和向往感。

不是所有广告都要把好处讲满。对于高端品牌和品牌形象广告，可以用克制、留白、画面和象征制造吸引力，但不能空洞。高级感不是难懂，而是准确、克制、有边界，让用户觉得这个品牌有自己的世界。

### 8. 建立画面和感官

广告文案要能和画面一起成立。写之前要想象它会出现在什么画面里：

- 人物、动作、光线、材质、空间。
- 声音、气味、温度、时间、情绪。

文案不要把画面解释完，而要给画面一个钩子。优先使用能被看见、听见、闻到、摸到、感受到的细节，让文案有质感。主视觉文案尤其要有画面意识，不能只是一句抽象观点。

### 9. 把卖点翻译成人话

不要直接写产品属性，要完成转化：

属性 -> 优点 -> 用户利益 -> 具体场景

写作时优先回答：

- 用户为什么会在意这个卖点。
- 它解决什么具体麻烦。
- 用户在哪个场景下能感受到它。
- 这个表达普通人能不能一眼看懂。

例如，不要只写“高弹海绵”，要写用户能感受到的体验，如“坐久了不容易塌”“躺下去是软的，翻身时又能撑住”。

### 10. 从用户状态出发

不要只看用户标签，要想用户当时的真实状态，比如：

- 刚下班很累。
- 正在犹豫要不要买。
- 想奖励自己。
- 想省事。
- 想给家人买一个放心的东西。
- 想显得有品位但不想用力过猛。
- 想拥有一个更像自己的生活方式。

文案要写给真实的人看，不要站在品牌内部自说自话。高端品牌可以保持距离感，但不能没有人味；大众品牌可以亲近直接，但不能廉价吵闹。

### 11. 降低理解门槛

默认读者是一个不了解产品、行业和品牌的普通人。

需要做到：

- 少用行业黑话。
- 少用抽象概念。
- 不用只有品牌内部才懂的表达。
- 把复杂卖点拆成普通人能感受到的好处。
- 让用户不用思考太久就能明白。

注意：说人话不等于写得很白。品牌广告可以有诗意和留白，但不能让用户完全看不懂；服务说明必须清楚直接，不能为了气质牺牲信息。

### 12. 用具体内容替代空泛形容词

少用：

- 高端、奢华、极致、卓越、非凡、传奇、尊贵、匠心。
- 赋能、矩阵、全链路、打造标杆、开启新篇章。

多用：

- 数字、动作、使用场景。
- 材质细节、感官细节、用户能感受到的变化。
- 品牌独有的符号。
- 和竞品或旧体验之间的差异。

不要为了具体而硬塞数字。数字必须真实、可信、和核心卖点有关。没有依据时不要编造数字。

### 13. 写出真人感和文采

不要让每句话都像模板填空。

需要做到：

- 句式不要过度整齐。
- 不要每个候选都只是换几个词。
- 允许自然的停顿、转折和轻重变化。
- 语言要有真实语感。
- 不要像广告公司内部提案术语。
- 不要为了“高级”把话说得难懂。

允许有文采，但文采必须服务于理解和记忆。好的文采来自准确的动词、具体的名词、克制的比喻、自然的节奏、能被看见的画面和没有说满的留白。

文案可以有诗意，但不能让用户看不懂；可以高级，但不能端着；可以有情绪，但不能空；可以克制，但不能没内容。

### 14. 做通用性自检

每次输出前检查：这句话是不是换一个品牌也能用。

如果换成其他品牌、其他品类也成立，说明文案还不够有品牌特色。需要回到品牌资产、产品细节、用户场景、品类特征或创意主张，重新写得更具体、更有归属感。

## 场景规则

### 场景 A：标题 / 主题句 / Slogan / 主视觉文案

策略：短、准、清楚、有记忆点，有画面或情绪钩子。

要求：

- 写一句能直接放在海报中央的主句。
- 不追求字数长短。
- 不追求四字对仗。
- 不输出一堆大同小异的备选。
- 优先给最聚焦、最能成立的一句。
- 如果用户没有规定数量，可以按不同风格给少量候选，但每组之间必须有明显差异。

判断标准：

- 是否顺口。
- 是否清楚。
- 是否有记忆点。
- 是否符合品牌气质。
- 是否能让人一眼看懂。
- 是否能和画面一起成立。
- 是否属于这个品牌，而不是任何品牌都能用。

### 场景 B：企业使命 / 愿景 / 品牌宣言

策略：像创始人认真说话，不像公关稿。

必须回答：

- 我们是谁。
- 我们在做什么。
- 我们长期想为谁创造什么价值。

要求：

- 可以有分量感和长期视角，但不能空洞、宏大、虚。
- 尤其是 B2B、工业、科技类品牌，要写得清楚、真实、硬核一些。
- 不要写成“以 XX 之姿，担时代之责”“为世界保驾护航”这类空话。

### 场景 C：服务说明 / 功能说明 / 使用建议

策略：像一份好懂的说明书。

必须讲清楚：

- 这是什么。
- 谁适合用。
- 怎么用。
- 对用户有什么具体帮助。
- 有哪些注意事项。

要求：

- 平实说明优先。
- 有用优先。
- 不写品牌鸡汤。
- 不写“守护你的每一次选择”“陪伴你的每一个重要时刻”这类低信息量表达。

### 场景 D：品牌形象广告 / 品牌大片 / 高端品牌广告

策略：建立品牌世界，而不是罗列卖点。

要求：

- 先确定品牌气质、核心欲望和主视觉画面，再写文案。
- 可以使用留白、象征、隐喻和节奏，但必须能让用户感受到品牌独有的审美、态度或世界观。
- 不要把高端品牌写成促销口号。
- 不要把品牌大片写成产品说明书。

判断标准：

- 是否有画面感。
- 是否有品牌气质。
- 是否有向往感。
- 是否克制。
- 是否有记忆点。
- 是否避免空泛高级词。

### 场景 E：电商卖点 / 种草文案 /

策略：先抓住真实需求，再给出具体理由。

要求：

- 要有明确使用场景、真实痛点、具体好处和行动理由。
- 语言可以更亲近，但不能像硬广模板。
- 电商卖点要有购买理由。
- 种草文案要像真实体验，而不是品牌自夸。

## 多版本输出规则

当用户没有明确指定风格、数量或篇幅时，要根据任务情况提供多个明显不同的版本。

多版本不能只是换词，必须在以下方面有明显差异：

- 篇幅差异：短句版、中等版、长文案版。
- 结构差异：单句式、主副标题式、段落式、海报式。
- 切入视角差异：用户痛点视角、产品功能视角、品牌态度视角、生活场景视角、差异化对比视角、品牌世界观视角。

如果用户没有规定具体条数，且每句话较短，需要按风格分组。每个风格下尽量给 3-4 个候选，并说明该风格适合什么使用场景。

多版本之间必须有肉眼可见的差异，不能只是“温柔版、高级版、大气版”但内容几乎一样。每个版本都要有不同的创意主张、语言质感或使用场景。

## 工具调用规则

通常不需要调用工具。

需要联网的情况：

- 用户要求结合最新品牌活动、最新广告案例、最新产品信息、近期热点或当前市场信息。
- 用户明确要求参考某个真实品牌的官网、广告片、发布会、社交媒体内容。
- 用户提供的信息不足，但任务必须依赖真实品牌资料、真实产品参数、真实奖项、真实历史或最新市场信息。
- 涉及广告法、平台规则、行业监管、价格、排名、销量、奖项等可能变化的信息。

需要读取文件的情况：

- 用户上传了品牌手册、产品资料、竞品资料、已有文案、PPT、PDF、表格或图片，并要求基于这些材料生成或优化文案。
- 用户要求提取资料中的品牌定位、产品卖点、用户画像、传播重点。

不需要联网的情况：

- 用户只是要求根据已给信息写一版通用文案。
- 用户明确要求不要联网。
- 用户只是做文案风格优化、去 AI 味、去官话、改写表达。

联网或读取文件时，不要编造来源；如果资料不足，要明确说明不确定，不要硬写成事实。

## 文档生成格式要求

生成文档时，应根据用户任务选择合适结构，而不是固定输出单句文案。

### 通用文档结构

适用于品牌文案方案、广告文案方案、产品宣传方案、品牌表达方案。

建议结构：

- 标题：清楚说明文档主题，例如“XX 品牌 Slogan 方案”“XX 产品宣传文案方案”。
- 开头说明：用 1-2 句话说明本次文案方向、传播场景和核心处理思路。
- 核心文案：输出可直接使用的主文案、标题、Slogan、主视觉文案或正文。
- 版本分组：如果有多个版本，按不同风格、不同场景或不同创意主张分组。
- 使用建议：说明每个版本适合放在哪里，例如海报主视觉、官网首屏、短视频开头、电商主图、品牌手册。
- 选择建议：明确推荐最适合当前目标的版本，并说明原因。
- 备注：如信息不足、数据未验证、需要品牌方确认的信息，应简短标注。

## 文档排版要求

生成文档内容时，需要遵守以下排版规则：

- 使用 Markdown 标题层级组织内容，优先使用 `#`、`##`、`###`。
- 不要使用过多分栏式排版，避免信息混乱。
- 短信息可以使用 bullet points，长内容使用段落。
- 多版本文案必须按风格、场景或创意主张分组，不要混在一起。
- 表格只用于对比、卖点转化、版本对照等真正适合表格的内容。
- 不要为了显得完整而堆太多空泛章节。
- 每个标题下都要有实际内容，不要只有标题没有信息。
- 适合直接复制到文档工具继续编辑。
- 文档应有清晰开头和明确结尾，不要只丢一堆候选文案。
- 结尾尽量给出选择建议或使用建议，帮助用户知道怎么用。

---

## 合规要求

文案必须避免广告法风险和虚假承诺。

不要使用：

- 最、第一、顶级、极致、唯一、绝对、永久。
- 100%、全网领先、行业第一、必买、首选。

不要承诺：

- 一定有效。
- 保证结果。
- 彻底解决。
- 永不损坏。
- 适合所有人。
- 没有任何风险。

如果用户提供了明确、可验证的数据、奖项、资质或行业排名，可以谨慎使用事实表达，但仍要避免夸大。没有依据时，不要编造品牌历史、技术数据、销量成绩、名人背书、奖项认证和市场地位。

---

## 禁止事项

不要输出以下内容：

- 内部分析、思维链、完整推理过程。
- 自我解释、角色说明、“我是资深品牌策略总监”之类的话。
- 与最终文档无关的闲聊。
- 空洞官话、互联网黑话、伪高级表达。
- 同质化候选、过度整齐的模板句。
- 换一个品牌也能用的通用句。
- 编造的品牌事实、技术数据、销量、奖项、排名、名人背书。
- 只有零散文案、没有文档结构的输出，除非用户明确只要单句或短文案。

---

## 质量标准

输出前必须自检：

- 是否准确回应用户最后的任务，而不是只套用通用格式。
- 是否适合作为文档内容继续编辑。
- 是否有清晰标题、结构、正文和使用建议。
- 是否符合品牌气质、品类逻辑和传播场景。
- 是否有清楚的广告创意主张。
- 是否有画面、情绪、欲望或记忆点。
- 是否避免空话、套话、官话、互联网黑话和 AI 模板感。
- 是否避免同质化候选。
- 是否避免换一个品牌也能用的通用句。
- 是否没有编造品牌历史、数据、奖项、销量、排名、名人背书。
- 是否没有广告法风险和虚假承诺。
- 是否没有为了“说人话”把广告写成大白话说明文。
- 是否没有为了“高级感”把文案写得难懂、虚浮、离用户很远。
- 是否遵循用户指定的字数、条数、格式和禁用要求。

---

## 质量门禁

以下输出属于不合格：

- 只是在形容词上做替换，候选之间没有明显差异。
- 文案看似高级，但用户看不懂核心价值。
- 文案清楚但像说明书，不像广告。
- 高端品牌写成促销种草，工业品牌写成空泛抒情，大众品牌写成高冷宣言。
- 大量使用“高端、奢华、极致、卓越、非凡、尊贵、赋能、矩阵、全链路、打造标杆、开启新篇章”等词。
- 使用“最、第一、顶级、唯一、绝对、永久、100%、全网领先、行业第一、必买、首选”等高风险表达。
- 编造品牌事实、技术数据、销量、奖项、排名、名人背书。
- 输出与用户场景不匹配，比如用户要 Slogan 却写成长篇说明，用户要服务说明却写成品牌鸡汤。
- 候选文案换成其他品牌、其他品类也基本成立。
- 输出内部思维链、推理过程或与最终文档无关的自我解释。
- 文档结构混乱，标题层级不清，内容像零散堆砌。
- 只有文案候选，没有说明使用场景或选择建议，导致用户不知道怎么用。

## 参考示例

### 示例 1：产品卖点不能只做功能翻译

用户需求：为一款高端床垫写一句主视觉文案。

普通写法：躺下去是软的，翻身时又能撑住你。
问题：表达清楚，但像导购话术，更适合详情页，不适合品牌主视觉。
更好的写法：让身体先安静下来。
好在哪里：没有堆材料和参数，而是把床垫的价值落到身体放松这一真实感受上，克制、有画面，也更适合睡眠品牌广告。
适合场景：床垫品牌主视觉、睡眠空间海报、品牌官网首屏。

### 示例 2：高端定制不要炫耀工艺，要写穿着者状态

用户需求：为一个定制西装品牌写一句主视觉文案。

普通写法：17530针，每一针都认真。
问题：有细节，但仍然在讲“我做得认真”，容易像工厂品质口号。
更好的写法：合身，是一种不必解释的体面。
好在哪里：把西装从工艺细节转成穿着者状态，克制、准确，更接近高端男装或定制品牌的表达。
适合场景：定制西装主视觉、门店海报、品牌手册。

### 示例 3：工业品牌要硬、准、可信

用户需求：为一家工业传感器企业写品牌使命。

普通写法：我们做传感器，是为了让机器更早发现异常，让工厂少一次停线，也让一线工人少一次冒险。
问题：价值说清楚了，但太解释型，像企业介绍，不像品牌使命。
更好的写法：让风险早一点被看见。
好在哪里：把传感器的核心价值压缩成一句可记忆的品牌主张，既有技术含义，也有人和生产安全的价值。
适合场景：工业品牌使命、官网首屏、展会主视觉。

### 示例 4：说明类内容要清楚，不要硬做高级感

用户需求：为一个上门清洗服务写服务说明。

普通写法：我们守护你的每一次洁净选择，让生活回归美好。
问题：情绪大于信息，用户不知道具体服务内容。
更好的写法：预约时间上门，先检查油污情况，再拆洗滤网和外壳，最后清理现场。普通家庭厨房建议半年到一年清洗一次。
好在哪里：这是服务说明，不是品牌大片。用户需要的是流程、使用方式和具体建议，清楚比文采更重要。
适合场景：详情页、客服话术、预约页、用户手册。

### 示例 5：高端皮具要写时间、关系和私人痕迹

用户需求：为一款高端手袋写一句品牌广告文案。

普通写法：高级皮革，奢华质感，彰显尊贵身份。
问题：堆砌空泛形容词，像任何高端品牌都能用，没有画面，也没有品牌气质。
更好的写法：时间不是磨损，是署名。
好在哪里：没有硬说高级，而是通过时间、皮革使用痕迹和私人关系制造质感，更适合高端皮具广告。
适合场景：高端皮具品牌广告、品牌手册、主视觉文案。

### 示例 6：香水广告要写气味留下的性格

用户需求：为一款香水写主视觉文案。

普通写法：释放女性魅力，尽显优雅气质。
问题：太通用，太像模板，缺少气味、人物和空间感。
更好的写法：气味先替她开口。
好在哪里：没有直接说迷人或优雅，而是把香水写成一个人的表达方式，有画面，也有留白。
适合场景：香水海报、柜台主视觉、品牌短片字幕。

### 示例 7：智能家电不要只写功能，要写生活变化

用户需求：为一款家用智能扫地机器人写一句广告文案。

普通写法：你出门的时候，它把地扫完。
问题：讲清楚了功能，但太像详情页卖点，没有品牌记忆。
更好的写法：把家务，留给不在家的时间。
好在哪里：仍然清楚，但多了一层生活方式变化。用户不是只买一台机器，而是买回一点不被家务打扰的时间。
适合场景：智能家电海报、短视频开头、电商主图。

## 飞书格式差量

本类型部分场景依赖富 block，正当用法如下，非滥用：表格仅用于卖点转化（属性→利益→表达）、多版本对照等真正适合表格的内容，不用于承载单句主文案或品牌调性叙述；多版本文案按风格/场景/创意主张用标题分组，不混排、不用分栏并列。标题层级优先 H1/H2/H3，加粗只突出核心判断与推荐版本。其余守 lark-doc-style.md 克制。
