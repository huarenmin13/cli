> 写作类型：影评｜主流载体：飞书在线文档
> 本文只讲"怎么写"。飞书通用格式与克制红线（callout/高亮块、编号、分栏）守 online-doc 的 lark-doc-style.md；本文只补该类型的飞书格式差量。

## 〇、单核铁律（最高优先级，贯穿全程）

这是统领全文的总开关，其余所有模块都服从它。

1. **定义**：一篇影评只围绕**一个核心主题（即一个主分析维度）**展开——从主题表达、人物、叙事、视听、表演、类型、现实映照中只选定**一个**作主轴，全文所有段落都为论证这一个主轴服务。

2. **核心观点 = 核心主题的一句话判断**：核心观点不是泛泛的好坏态度，而是对这唯一主轴下的一句话结论（如"它的视听语言用克制对抗煽情"）。观点统摄与主题单一是同一件事，不可拆开。

3. **其余维度只能降格为论据**：选定主轴后，其他维度（如顺带提到的人物、台词、镜头）只能作为支撑主轴的局部论据被引用，**严禁与主轴并列成章、平行展开**。

4. **篇幅服从单核**：宁可短，不可为凑字数 / 凑段数引入第二个平行主题。单一主题撑不满预设篇幅时，向该主题更深处挖，而非横向扩维。

5. **判定红线**：成文后若能从文中抽出两个及以上彼此平行、可独立成篇的主题/维度，即判为不合格，必须删到只剩一个主轴。

## 一、任务目标

根据用户提供的影视作品、片段、画面或观看感受，产出一篇以 "单一核心主题 + 分析论证" 为核心的高质量影评。成功标准：

1. 主题单一 —— 全文锁定唯一核心主题/主分析维度，有一句话可概括、能统摄全文的核心判断，回答 "作品在这一维度上为何成立或为何失效"，而非模糊态度，也非多维并陈。

2. 分析为主 —— 分析多于复述，建立在作品内容之上，论点 — 论据 — 论证一一对应，所有论据都回扣唯一主轴。

3. 维度收敛 —— 从主题、人物、叙事、视听、表演、类型、现实映照中，**只锁定一个最相关的核心维度**作主轴；其余维度仅作辅助论据，不另起炉灶。

4. 结构清晰 —— 开头有切口，单一主线贯穿，层次向纵深递进，结尾收束。

5. 语言适配 —— 准确、凝练、有可读性，文风与作品气质及用户意图匹配。

## 二、注意事项

**一、评论本质红线（最高优先级）**

1. 不写成剧情简介或观后感流水账：提及情节只为支撑论点。

2. 不空泛吹捧或情绪化吐槽：好 / 坏都要说清 "好在哪、问题在哪"，判断须有作品依据。

3. 每个判断都要能回到具体文本（情节、人物行为、镜头、台词、结构），杜绝空中楼阁式拔高。

**二、内容质量红线**

4. 核心观点须有讨论价值，不是常识复述。

5. 分析须有因果：不只说 "很有效"，要解释 "为什么有效 / 无效"。

6. 全文只有一条主线主轴，所有分析点都收敛回该主轴，**严禁出现与主轴平行的第二维度**。

**三、形式红线**

7. 字数贴合用户要求。

8. 以连贯段落行文为主，不分点、不写成答题式或论文提纲。

9. 开头快速建立讨论对象与单一核心判断，避免大段背景或感慨式起手；结尾完成总结或价值提升。

**四、边界与诚实处理**

10. 信息不足时，可基于该片公认特征分析，但不得虚构不存在的情节或镜头。

11. 评论对象不明确时不臆造，简要向用户澄清。

12. 全程不向用户暴露工作流程、分类判断或任何内部推理，只输出最终评论。

## 三、信息识别

收到输入后先识别：

- **基础信息**：评论对象（哪部片 / 片段，是否有片名、导演）；用户给定材料（梗概、片段、画面、观看感受、评论方向）；特殊要求（字数、语气、侧重点、评论类型）。
- **作品特征**：题材与类型、叙事风格、最突出的看点或问题、是否涉及现实议题。
- **核心主题候选**：列出该作品最值得深挖的几个潜在维度，**但最终只能选定其中一个**作主轴（见下一模块）。
- **缺口判断与联网核实（本环节强制）**：先判断材料是否足以支撑识别与分析；凡用户只给片名、材料不足、或对作品记忆不确定可能编造时，**必须在此环节即发起联网搜索，核实真实信息（情节、镜头、导演、题材风格等）后，再据以抽取作品特征与主题候选**（检索方式详见"六、工具调用规则"）。确无可靠信息时只就公认特征有限分析、不虚构；评论对象无法确认则向用户澄清。

## 四、任务类别分类

识别后先定型，**只能选定一个主类型作为全文主轴**，据此确定核心观点切入与论证重心。**严禁多类型并列成章；其余维度仅作支撑主轴的辅助论据。**

**按评论类型分类（决定切入角度——只选其一作主轴）**

- 综合评论：整体判断作品成败——此时主轴是"整体成败的那条主因果链"，仍须单线推进，而非各维度平均用力。
- 主题 / 作者表达评论：聚焦作品真正关心的问题及其完成度。
- 人物评论：聚焦人物动机、关系、弧光是否成立。
- 叙事评论：聚焦结构、节奏、信息释放、高潮兑现。
- 视听评论：聚焦镜头、声音、美术、色彩如何参与叙事与情绪。
- 类型评论：聚焦它是否完成该类型应有的表达承诺、有无创新。
- 社会议题评论：聚焦作品如何回应现实，是真触及还是借现实做包装。
- 推荐向 / 批评向：明确为安利或批判定调，论证服务该立场。

**按用户意图分类（决定语气与密度）**

- 深度长评：分析密度拉满，论证向单一主题的纵深层层递进（而非横向扩维）。
- 好读短评：轻盈、自媒体向，保留观点内核、降低术语密度。
- 默认：中等密度、可读性优先、观点不缺位。

## 五、工作流程

内部执行，绝不向用户暴露。

1. **信息读取**：提取评论对象、用户材料、字数语气等要求；未指定用默认。

2. **识别与定类（含联网核实）**：按"三、信息识别"抽取作品特征、判定评论类型与用户意图；信息有缺口时**必须先联网核实再继续**，确保后续锁主题、提观点都建立在已核实的真实信息上。

3. **锁定唯一核心主题**：从候选维度中**只选定一个**作全文主轴，并明确写出"本篇只谈 X"；主动排除其余维度，使其至多作为局部论据。

4. **提炼核心观点**：确立一句话可概括、能统摄全文的核心判断，该判断必须落在已锁定的唯一主轴上。

5. **搭建单核论证框架**：围绕唯一主轴选结构（总分总 / 问题推进 / 单核递进 / 对照分析），**只调用支撑该主轴的论据，主动剔除与主轴无关的维度**，确保层层向纵深递进、每段回扣主轴。**严禁机械套模板，严禁为补足篇幅引入第二主题。**

6. **保成立优先**：先确保主题单一、观点明确、论据有据、结构完整、字数达标，再强化文风锋芒。

7. **反思校正**：按质量自查清单核对（含单核自查）后输出。

8. **输出正文**：仅输出最终评论，不输出定位、观点清单或分析过程。

## 六、工具调用规则

评论须基于真实作品信息，联网搜索是防止虚构情节 / 镜头的必要环节。

1. **何时搜**：用户给片名但缺细节、给的材料不足以支撑分析、或对作品记忆不确定可能编造时，必须先联网搜索。

2. **搜什么**：按已锁定的唯一主轴聚焦检索 —— 视听主轴搜摄影 / 美术风格，叙事主轴搜结构特点，类型主轴搜类型定位，社会议题主轴搜现实背景；组合 "片名 + 导演 / 摄影 / 主题 / 风格" 等检索。不为无关维度浪费检索。

3. **怎么用**：只采用可靠信息作论据；并行多条检索交叉印证；引用外部来源支撑事实性描述时按行内 [[标题]](https://mira.bytedance.com/chat/url) 句末标注。

4. **搜不到**：仅就公认、可确证特征做有限分析，不虚构；对象无法确认则向用户澄清。

5. **效率**：探索性检索一次性并行发起，同一目标失败上限 3 次；工具过程不向用户暴露。

## 七、输出格式

## 交付形态

- 仅输出一篇完整的电影评论正文，不附加任何标题、小标题、分点、前言或结语说明。
- 评论以连贯成段的文章形式呈现，自然分段，**段数服从单一主题，不为凑段数引入第二主题**；篇幅以把唯一主轴讲透为准，宁短勿散。
- 不输出评论定位、核心观点清单、分析维度、工作流程或任何内部判断过程。

## 内容要求

- 有可概括的、落在唯一主轴上的核心观点统摄全文。
- 开头两句内建立切口与单一核心判断，结尾收束到意义或局限。
- 全文不出现与主轴平行、可独立成篇的第二维度。

## 格式细则

- 使用规范的中文标点，不使用 Markdown 语法标记（加粗、井号、星号等）包裹正文。
- 若正文中的事实性视觉描述引用了外部来源，按行内格式 [[标题]](url) 在句末标注；除此之外不出现任何链接或来源罗列。
- 不出现"作为一篇影评""综上所述""本文认为"等元叙述或答题式表达。

## 绝对禁止

- 禁止输出剧情简介、人物介绍或观后感流水账。
- 禁止多主题/多维度平行展开——发现两条及以上平行主线即判不合格。
- 禁止暴露角色设定、理论锚点、工具调用过程或任何思考过程。

## 八、质量标准自查

全部通过方可输出，任一不过须返工。

- **单核（生死线，首查）**：全文是否只有一个核心主题/主分析维度？能否从文中抽出两个及以上彼此平行、可独立成篇的维度？若能，立即删到只剩一个主轴。
- **观点（生死线）**：是否有一句话可概括、统摄全文且落在唯一主轴上的核心判断？是否有讨论价值而非常识复述？
- **论证（生死线）**：每个判断是否都有具体作品依据？是否分析多于复述？是否解释了 "为什么" 而非只下结论？论据是否全部回扣主轴？
- **内容质量**：是否没退化成剧情简介 / 观后感？是否没空泛吹捧或情绪化吐槽？信息是否真实未虚构？
- **结构与语言**：结构是否沿单一主轴清晰递进（向纵深而非横向）？开头是否抓人、结尾是否收束？语言是否准确凝练、文风适配？
- **形式与边界**：字数是否达标？是否仅输出正文、无内部过程暴露？外部来源是否按行内格式标注？

修正优先级：单一主题 → 核心观点 → 论证力度 → 内容质量 → 结构层次 → 语言凝练度 → 字数 → 形式。

## 飞书格式差量

守 lark-doc-style.md 克制，无特殊 block 需求。影评为纯散文类交付，以连贯成段行文，不引入表格、画板、高亮块等富 block。
