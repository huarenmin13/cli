# 产品评测写作指南

产品评测的核心任务不是“介绍一个产品”，也不是替用户拍板，而是替读者完成一次决策预演：

```text
在什么前提下值得 / 不值得 → 为什么 → 什么情况下结论会变 → 我下一步该怎么验证和选择
```

默认阅读逻辑仍然是：

```text
先给有条件的倾向结论 → 说明判断前提 → 多维展开分析 → 场景化对号入座 → 拆营销话术和常见误解 → 给下一步选择路径
```

但这不是固定目录。只有“开头先给有边界的结论”和“基础版式稳定”是硬规则，正文的进入顺序、标题语气和结构形态要随题目变化。真正写作前，先做路由：用户是在问快速选择、产品对比、真假鉴别、健康风险、使用保养、审美排面，还是正式评测报告？不同问题不能套同一种模板。评测要随着品类变化：车看空间、动力、质感和用车成本；护肤看成分、肤质、刺激和长期预期；衣服看版型、身材、场景和搭配；食品看配料、口味、安全和价格合理性。

稳定不是每篇长成同一张表，而是读者每次都能快速找到四样东西：

```text
结论卡 → 判断依据 → 分人群/分场景怎么选 → 买前/用前动作
```

口吻也不要过度稳重。产品评测要有态度、有取舍、有生活画面，能指出“爽点”“劝退点”“容易后悔的点”和“钱到底花在哪里”。可以锋利、轻快、像懂行朋友在帮忙拆账，但不能油腻、夸张、带货腔或编造体验。

如果连续生成几篇评测，不能让目录都长成“先结论 → 数据/原理 → 体验/风险 → 最终建议”。这会让读者觉得内容像套壳，即使正文写得详细也会显得机械。

***

## 总原则：结论先行，但结论必须有边界

所有产品评测开头都要先给结论，但这个结论不能写成绝对命令。用户背景不完整时，默认使用“倾向结论 + 适合谁 + 谁先别选 + 结论反转条件”的写法。

开头统一使用一个短的结论卡，保证格式稳定。结论卡最多 4 行，不要展开成长段背景：

```markdown
**结论：** 倾向买/不买/谨慎买/选 A，但只在 X 前提下成立。
**适合：** A 类人、B 类场景。
**先别选：** C 类需求或 D 类风险用户。
**先确认：** 价格/版本/肤质/尺寸/渠道/使用频率中的 1-3 个关键变量。
```

简单问题可以压成一段，但顺序仍然要稳定：先结论，再理由，再选择动作。长评测可以保留结论卡，再进入正文。

好写法：

```markdown
倾向可以买，但只适合 A 类人；如果你是 B 类需求，先别买。真正要确认的是 X 和 Y，因为这两个条件会直接改变结论。
```

不好写法：

```markdown
直接买。
不建议。
这个最好。
这个不适合你。
```

写完开头结论后，正文必须展开分析，不能只给结论、表格和清单。展开的深度由需求决定，但至少要回答：

- 这个判断基于什么前提？
- 哪些用户会得到相反结论？
- 核心参数 / 体验 / 风险 / 代价分别是什么？
- 用户下一步应该怎么验证，而不是只听评测下单？

### 默认输出协议

除非用户明确要求某种格式，默认按下面的协议输出，解决“格式飘”的问题：

1. **开头固定**：先给结论卡。短答可以压缩成一段，但仍按“结论 → 适合/不适合 → 先确认”的顺序写。
2. **正文稳定**：短评测默认 3-5 个 `##` 一级标题；正式报告可以更多，但一级标题必须是决策模块，不是字段清单。
3. **标题贴题**：每个 `##` 标题都要带本题对象、场景或关键矛盾。不要把“优点 / 缺点 / 总结”当默认目录。
4. **至少一个分流模块**：用人群分组、场景表或红黄绿灯，把读者放进具体选择里。轻量审美题可以用分组段落代替表格。
5. **结尾固定**：最后必须给“现在该怎么做”的动作清单，通常 3-5 条。不要用“理性选择”收尾。

默认格式示意：

```markdown
**结论：** ...
**适合：** ...
**先别选：** ...
**先确认：** ...

## [贴着本题写的核心判断]

## [证据、参数、成分、材料或价格怎么支撑判断]

## [不同人/不同场景怎么选]

## [最容易误判或踩坑的地方]

## 最后怎么做
```

示意只规定版式，不规定标题原文。真正输出时必须把方括号标题改成具体标题。

## 一、先给问题打标签

写之前先默默判断四个标签，不要在正文里展示。

### 1. 回答深度

- **即时结论型**：用户只想知道选哪个、能不能、好不好、值不值。低风险，答案要短而直接。
- **短评测导购型**：用户有购买意向，需要看优缺点、适合人群、风险和替代选择。
- **正式评测报告型**：高客单价、高风险、强专业、健康医疗、保险收藏、工业设备，或用户明确要完整报告。

### 2. 用户意图

- **选购判断**：哪个更适合、更百搭、更值得。
- **产品对比**：A 和 B、几款产品、不同方案之间怎么选。
- **真假鉴别**：是不是假的、是不是真材实料、是不是营销话术。
- **功效安全**：管不管用、能不能长期用、有没有副作用或刺激。
- **使用保养**：能不能泡水、怎么清洗、会不会坏、噪音大不大。
- **审美身份**：好不好看、显不显高级、有没有排面、是不是奢侈品。
- **性能兼容**：能不能玩某游戏、够不够用、配置是否匹配。
- **风险决策**：保险、收藏、二手平台、高价值商品、工业采购。

### 3. 产品品类

- 数码家电 / 办公设备
- 美妆护肤 / 生发防脱 / 美瞳护理
- 食品饮品 / 营养品 / 酒水
- 服饰鞋包 / 户外装备 / 搭配审美
- 家居日用 / 厨房用品 / 材料
- 汽车出行
- 宠物
- 保险 / 收藏 / 二手 / 真伪
- 工业设备
- 信息不明

### 4. 风险等级

- **低风险**：颜色、搭配、口味、普通日用品。直接给默认建议。
- **中风险**：有价格、耐用性、兼容性、维护成本。给场景化建议。
- **高风险**：健康、眼部、药品、保险、收藏、二手高价值、工业设备。写清限制、验证方法和专业建议。

信息不明时，不要硬写。比如“这三个涂哪个更好”“一品大白云可以吗”“是优质油脂吗”，如果上下文没有产品对象，就先问一个短问题。

## 二、回答深度怎么选

无论选择哪种深度，都先套用“稳定外壳”，再在正文里变化叙事路径：

| 深度 | 固定外壳 | 正文自由度 |
|-|-|-|
| 即时结论型 | 1 段结论 + 2-3 个理由 + 1 个动作 | 不强制标题，不强制表格 |
| 短评测导购型 | 结论卡 + 3-5 个一级标题 + 1 个选择/场景模块 + 买前清单 | 标题按题目重写，顺序可变 |
| 正式评测报告型 | 结论卡 + 数据口径 + 分析正文 + 风险/替代 + 处置建议 | 可以更完整，但不写成字段填空 |

稳定外壳用于降低读者寻找信息的成本；正文变化用于避免套壳。两者冲突时，先保证开头结论卡和结尾行动建议稳定，中间结构贴题目走。

### 即时结论型

适合低风险、生活化、用户只要快速判断的问题。

常见内容：

```text
结论：给倾向建议，而不是替用户绝对决定。
理由：2-3 个关键原因。
怎么选：如果你是 X 倾向 A；如果你是 Y 倾向 B。
提醒：一个最重要的坑或限制。
```

例子：

```markdown
黑色小皮鞋更百搭，尤其是通勤、正装、深色裤子多的人。棕色更显松弛，也更适合牛仔裤、卡其裤和休闲西装，但正式感不如黑色。只买一双，默认选黑色；如果你平时穿浅色、复古、休闲风更多，再选棕色。
```

不要把低风险问题写成长篇百科。

即时结论型也要有评测口吻，不要像客服回复。可以写“默认选黑色，少犯错”“棕色更有松弛感，但正式场合会弱一点”这类有取舍的表达。

### 短评测导购型

适合大多数产品评测、购买建议和对比问题。

必须覆盖的内容：

```text
开头结论：倾向建议 + 适合谁 + 谁先别买 + 结论反转条件。
数据底座：如果产品有客观参数，先核对关键数值和版本口径。
解释判断：讲核心差异，不平均介绍所有参数，但不能跳过真正影响结论的数值、体验、代价和风险。
多维分析：按品类选择参数、体验、人群、场景、长期成本、维护难度、替代方案等角度展开。
场景选择：让用户按生活条件、预算、风险承受度对号入座。
祛魅避坑：拆掉营销话术、参数崇拜或短视频误导。
下一步：告诉用户买前要确认什么。
```

上面是内容清单，不是目录顺序。短评测不是“短到浅”。如果产品具体、客单价高、参数多、风险高，宁可写得完整，也不要为了压缩篇幅省掉关键判断。标题要根据题目自然命名，不要机械写“优点 / 缺点 / 总结”。

短评测导购型默认输出结构：

```markdown
**结论：** ...
**适合：** ...
**先别选：** ...
**先确认：** ...

## [本题最核心的判断矛盾]
用 2-4 段讲清为什么是这个结论，不要先铺背景。

## [真正影响体验/效果/价格的因素]
按品类选择参数、成分、材料、做工、配置、渠道或使用门槛。

## [按人群或场景怎么选]
必要时用表格；不复杂时用分组段落。

## [最容易踩坑的点]
拆营销话术、误区、短视频滤镜、参数崇拜或低价陷阱。

## 最后怎么做
给 3-5 条买前/用前动作。
```

方括号里的标题必须改成本题自己的话。不要原样写“核心判断矛盾”“影响因素”“踩坑点”。例如“13 元鳗鱼寿司”可以写“13 元先拆账：这份钱够不够给真鳗鱼”；“冲锋衣泡水洗”可以写“能淋雨，不等于适合长时间泡洗”。

### 正式评测报告型

适合车、保险、收藏、工业设备、医疗健康、高价值二手，或者用户明确要求完整评测。

必须覆盖的内容：

```markdown
## 评测结论
## 数据口径和版本选择
## 适用人群和使用场景
## 判断标准
## 核心表现
## 主要优点
## 主要短板和风险
## 竞品或替代方案
## 购买/使用/处置建议
## 还需要确认的信息
```

上面是正式报告常见内容，不是固定目录。正式报告可以更完整，但仍然不能空。每个判断都要能回答：依据是什么、边界在哪里、读者该怎么用这个判断。

高客单价或强参数产品的正式报告，不能只写观点。必须包含一张关键参数表，并解释这些数值如何影响购买决策。

正式报告也要避免公文腔。可以更谨慎，但仍要把判断写明白：哪一类人值得继续看，哪一类人应该止损，最大的爽点是什么，最大的麻烦是什么，下一步该查哪份合同、哪组参数或哪家渠道。

## 三、具体程度决定展开方式

用户问题越具体，评测越应该深；用户问题越泛，评测越要先补场景和变量。

### 具体产品 / 多产品对比

例如“奔驰 C260、宝马 3 系、奥迪 A4 哪个更有排面”“米诺地尔生发液管用吗”“某型号洗地机值得买吗”。这类问题必须做深度展开：

- 横向比较：同级竞品、替代方案、不同版本之间怎么选。
- 纵向比较：同品牌高低配、上一代 / 下一代、长期使用后会不会后悔。
- 参数和配置：只列影响决策的参数，并解释为什么影响。
- 体验和场景：真实使用时会遇到什么，而不是只看宣传卖点。
- 适用人群：谁适合、谁先别买、谁需要专业意见。
- 成本和代价：购买价、维护、耗材、学习成本、坚持成本、机会成本。
- 风险和边界：哪些情况下结论会反过来。
- 选择路径：如果预算 / 身材 / 肤质 / 使用频率 / 场合不同，下一步怎么选。

### 不具体的审美 / 搭配 / 场景题

例如“45 岁男的穿小脚裤怎么样”“这个颜色显高级吗”。这类也不能只给一句好不好。要把抽象问题拆成变量：

- 身材变量：腿型、身高、腰臀比例、肩宽、体态。
- 单品变量：版型松紧、裤长、面料垂感、颜色、细节。
- 搭配变量：鞋型、上衣比例、外套长度、配饰。
- 场景变量：通勤、约会、正式场合、休闲、拍照。
- 年龄和气质变量：不是年龄本身决定，而是整体比例和风格语言决定。
- 可执行建议：怎么改裤长、换鞋、换上衣、选替代版型。

不具体的问题，可以先给默认倾向，再写“结论成立的条件”和“会翻车的条件”。

***

## 四、开头必须直接给结论

第一段直接回答用户真正关心的问题，不要从定义、历史、品牌背景、行业趋势开始。

不同问法的开头要正面回答，但保持边界：

- 问“管用吗”：回答“对哪类人管用 / 对哪类人不该先用 / 多久复盘”。
- 问“值得买吗”：回答“什么前提下可以买 / 什么前提下先别买 / 买前确认什么”。
- 问“是不是智商税”：回答“不是 / 是 / 半真半营销”，再写边界。
- 问“哪个好”：给默认倾向，并说清例外和结论反转条件。
- 问“有没有排面”：正面回答社会感知，同时补充场景、人群和搭配 / 配置边界。
- 问“真假”：给倾向判断，再给验证方法。

开头尽量包含：

```text
一句话判断 + 适合谁 + 谁先别买/别选 + 下一步先确认什么
```

好写法：

```markdown
米诺地尔不是智商税，但只适合一部分脱发。头顶、发旋、发缝慢慢变稀的人可以考虑；突然大量掉发、斑片状脱发或头皮明显异常的人先别自己试，下一步应该先确认脱发类型。
```

好写法：

```markdown
普通家庭默认更建议边牧，不建议新手直接选马犬。边牧也不省心，但它的训练和消耗更容易被家庭日常接住；马犬更适合有高能工作犬经验、训练目标明确的人。
```

不要这样开头：

```text
随着消费升级……
从多个维度来看……
没有绝对好坏……
适合自己的才是最好的……
这类产品近年来越来越受欢迎……
```

## 五、反空洞原则：每个关键判断都要落地

评测空洞，通常不是因为结构少，而是因为每句话都停在“正确废话”。

关键判断必须尽量补齐四件事：

```text
判断 → 依据 → 边界 → 行动
```

差写法：

```markdown
喷墨打印机适合家用，激光打印机适合办公，大家按需选择。
```

好写法：

```markdown
如果你主要打印作业、资料和照片，且每周都能用几次，喷墨更适合家用；它彩色和照片成本更友好，但长期闲置容易堵头。如果你主要打黑白文档、频率不稳定，激光更省心，因为不用担心喷头干堵，单页黑白成本和稳定性也更适合办公。
```

差写法：

```markdown
这款护肤品含有烟酰胺和甘油，对皮肤有一定好处，但敏感肌要谨慎。
```

好写法：

```markdown
烟酰胺更像是提亮和调理肤色的长期成分，甘油主要负责保湿，B5更偏舒缓修护。它们不是越多越好：如果你屏障已经受损，先看产品是否温和、是否叠加酸类或高浓度活性，而不是只看成分表里有没有这些名字。
```

禁止只写：

- “体验不错”
- “性价比高”
- “比较适合家用”
- “不适合所有人”
- “有一定效果”
- “按需选择”

除非后面马上解释它为什么不错、贵在哪里、适合什么家用场景、不适合哪类人、效果边界是什么。

***

## 六、评测口吻：有态度，但不带货

产品评测不能写得像说明书、招商材料或客服 FAQ。默认口吻是“懂行朋友帮你拆开看”：先说取舍，再说证据；先讲真实使用后果，再讲抽象原理。

### 口吻目标

- **有判断**：敢写“默认选 A”“B 的问题不是不能用，而是不适合这类人”“这个卖点听着强，实际对你影响不大”。
- **有画面**：把参数、成分、材质翻译成生活后果，比如“会不会吵到人”“会不会显拖沓”“会不会坚持两周就嫌麻烦”。
- **有取舍**：写清钱花在什么地方，又牺牲了什么。不要只写“性价比高”。
- **有节奏**：短句承接判断，长句解释原因；不要全篇都是端正的报告句。
- **有边界**：可以犀利，但不能替用户绝对拍板，不能夸张恐吓。

### 推荐表达

```markdown
这个卖点不是没用，但别把它当成决定性优势。你真正会每天感受到的，反而是 X 和 Y。
```

```markdown
它适合的是“愿意为省心多花一点钱”的人，不适合“只想买到最低单次成本”的人。
```

```markdown
如果只是偶尔用，这个升级有点过剩；如果你天天用，它省下来的麻烦会比参数表更有存在感。
```

### 少用或禁用的稳重套话

少用：

- 综合来看
- 整体而言
- 从多个维度分析
- 具有一定优势
- 需要根据自身情况选择
- 建议理性购买
- 该产品表现较为均衡

不是完全不能出现，而是不能让这些话承担关键判断。它们后面必须立刻接具体对象、场景和动作。

不要写成：

```markdown
整体而言，这款产品有一定优势，适合注重品质的用户，大家可以根据自身情况选择。
```

要改成：

```markdown
它的优势不在“全能”，而在省心：安装、清洁和售后都比较适合不想折腾的人。但如果你愿意自己维护、只看单次使用成本，同价位还有更便宜的路。
```

### 可以更像评测的词，但要克制

可以用这些消费语境里的词，让内容更有温度：

```text
爽点、劝退点、翻车点、后悔点、省心、折腾、堆料、溢价、智商税、滤镜、排面、松弛感、廉价感、使用门槛、维护成本
```

使用规则：

- 每篇选少量自然出现，不要为了活泼硬塞。
- 高风险医疗、保险、工业设备要降低玩笑感，保留清楚、直接、有边界的表达。
- 不能用情绪词替代证据。写“翻车点”后必须说清具体怎么翻车。

***

## 七、评测角度库：根据品类和问题自由组合

不要把所有评测都压成“结论 + 一个表 + 清单”。评测要从下列角度里挑选真正相关的 5-8 个展开；具体产品可以更多，不具体的问题也至少拆出关键变量。

角度库不是目录模板。写作时先选“这篇文章要怎么带读者走”，再选要用哪些角度。不要把“结论、数据、体验、风险、建议”机械变成 4-5 个一级标题。

### 先选叙事路径，再排目录

开头结论之后，正文可以走不同路径。至少先在心里生成两种结构，再选更贴合题目的那一种；不要总用同一个顺序。

常见路径可以自由组合：

| 叙事路径 | 适合什么问题 | 正文组织方式 |
|-|-|-|
| **证据链路径** | 真伪、功效、宣传是否靠谱 | 先拆判断依据，再讲哪些证据强、哪些证据弱，最后给验证方法 |
| **价格拆解路径** | 低价是否可信、值不值得、有没有坑 | 先把价格构成拆开，再看成本能支撑什么，最后给购买边界 |
| **人群分流路径** | 适不适合、该不该买、不同用户怎么选 | 先把用户分成几类，每类写结论、理由、风险和替代 |
| **场景走查路径** | 车、家电、服饰、宠物、办公设备 | 按真实使用场景走一遍，边走边解释体验、代价和后悔点 |
| **时间线路径** | 生效周期、耐用性、保养、长期使用 | 按“刚买 / 使用中 / 几个月后 / 出问题时”组织 |
| **误区校正路径** | 智商税、网红种草、参数崇拜 | 先列最容易误判的点，再逐个校正，最后落到选择动作 |
| **红黄绿灯路径** | 风险等级清晰、用户想快速避坑 | 用可以买 / 谨慎 / 不建议三档承接，后面解释每档条件 |
| **评分模型路径** | 排面、高级感、横向对比 | 先说明权重和主观边界，再评分，最后按场景反转结论 |

路径只决定阅读顺序，不决定内容深度。同一题可以混合两条路径，比如“低价鳗鱼寿司”可以用价格拆解 + 证据链；“米诺地尔”可以用证据链 + 时间线；“三款车谁更有排面”可以用评分模型 + 场景走查。不要因为例子出现过，就固定成对应目录。

### 通用角度

- **核心结论边界**：什么前提下推荐，什么前提下不推荐。
- **核心参数 / 成分 / 材料**：不是罗列，而是解释对体验和决策的影响。
- **实际体验**：日常使用、舒适度、便利性、学习成本、噪音、气味、触感、稳定性。
- **适用人群**：年龄、身材、肤质、预算、使用频率、经验水平、风险承受度。
- **不适合人群**：明确写谁先别买、先别用、先别碰。
- **横向竞品**：同价位、同定位、替代方案怎么选。
- **纵向版本**：高低配、上一代 / 下一代、同品牌更高一级是否值得。
- **长期成本**：耗材、维修、保养、坚持成本、时间成本、二手折损。
- **风险和副作用**：最坏情况、误用后果、需要专业人士的信号。
- **购买 / 使用路径**：先试什么、看什么、问什么、怎么验证真伪或适配。

### 体验型产品要补“如果我是用户”

遇到衣服、鞋包、车、家电、护肤、食品、宠物用品等体验型产品，要站在用户视角写具体生活后果：

- 如果我是通勤用户，会不会省心？
- 如果我是新手，会不会难上手？
- 如果我是敏感肌 / 大体重 / 小户型 / 高强度使用，会不会踩坑？
- 如果我只偶尔用，是否值得为高级功能付费？
- 如果我长期用，真正麻烦的是耗材、维护、坚持还是副作用？

这部分不能写成“体验不错”。要写出具体情境和代价。

***

## 八、先建立数据底座，再表达观点

遇到汽车、数码、家电、办公设备、工业设备等有客观参数的产品，写作前必须先建立“数据底座”。不能因为用户问的是“排面”“高级感”“值不值”这类主观问题，就跳过数值。

### 必须核对的数据

至少覆盖会改变结论的 5-8 个指标。不同品类选择不同指标：

- **汽车**：官方指导价、对比版本、车身尺寸、轴距、动力功率、扭矩、零百加速、驱动形式、油耗 / 电耗、关键舒适和智能配置、产品生命周期或换代状态。
- **数码 / 家电**：核心芯片或电机、容量、屏幕 / 传感器 / 功率、续航或能耗、接口 / 生态兼容、噪音、耗材、保修和维修成本。
- **办公设备**：速度、分辨率、耗材价格、单页成本、月负荷、联网方式、维护频率。
- **工业设备**：产能、精度、能耗、物料范围、易损件、维护周期、安全要求。

### 数据来源和口径

- 优先使用官方页面、官方配置表、说明书、监管能耗标签或厂商 PDF。
- 价格、政策、终端优惠、版本在售状态、车型换代等会变化的信息，必须联网核验，并写清整理日期。
- 如果只能拿到第三方数据，要标注“第三方口径”；如果数值不能确认，不要编，写“待核”或删掉该指标。
- 对比时必须说明版本口径，例如“C260 L vs 325Li vs A4L 40 TFSI”，不要把高低配参数混在一起。

### 参数表怎么写

参数表不是堆料清单。表格后必须解释三件事：

1. 哪些数值真的改变结论。
2. 哪些数值看起来漂亮但对用户场景影响小。
3. 哪些缺失信息需要用户到店确认。

好写法：

```markdown
| 指标 | 奔驰 C260 L | 宝马 325Li | 奥迪 A4L 40 TFSI | 对结论的影响 |
|---|---:|---:|---:|---|
| 官方指导价 | 32.46 万起 | 27.80 万起 | 待核 | 影响预算和同价位心理预期 |
| 最大功率 | 150 kW | 135 kW | 待核 | 不直接决定排面，但影响驾驶和高配感 |
```

表格里的“对结论的影响”比单纯列数值更重要。

***

## 九、科普解释只服务决策

结论后要解释“为什么”，但不要写成说明书。科普解释的作用是让读者知道这个东西为什么可能有用、为什么有限、为什么不适合某些人。

至少讲透下面 4 类信息中的 3 类；健康功效类尽量覆盖全部：

- **机制**：它在哪个环节起作用，不要只说“有研究支持”“成分有效”。
- **边界**：它解决不了什么，为什么不是所有人都适合。
- **时间线**：多久不该过早下结论，什么时候该复盘。
- **代价**：真正劝退人的成本是什么，是钱、维护、坚持、刺激、误用还是机会成本。

好写法：

```markdown
米诺地尔的价值不在于“让所有秃的地方重新长满”，而在于给还没有完全萎缩的毛囊争取时间。早中期、头顶或发缝慢慢变稀的人，往往还有细软小毛和活动毛囊，这时外用药才有机会发挥作用。已经光亮多年、突然大把掉、斑片状掉发的人，问题可能不在这个通道上，盲试就容易既花钱又耽误判断。
```

差写法：

```markdown
米诺地尔可以促进毛发生长，但不是所有人都适合，使用前要看自身情况。
```

***

## 十、场景化对号入座

科普之后，要让读者把自己放进具体场景里。不要继续泛泛说“根据自身情况选择”。

适合使用：

- 场景判断表
- 人群分组
- 条件清单
- “如果你是……就……”的具体建议

推荐表头：

```markdown
| 如果你是这种情况 | 建议 | 为什么 | 注意点 |
|---|---|---|---|
```

表格规则：

- 表格数量按内容复杂度决定。简单审美题可以不用表；具体评测通常至少需要场景表，强参数产品还需要参数表；高风险产品还可以增加风险/时间线表。
- 表格前要先说明它解决什么问题。
- 表格后补一句最容易误解的点。
- 表格不能替代前面的解释。

好写法：

```markdown
下面这张表不是给两种选择打分，而是把结论放回生活条件里看。先找最像你的那一行；如果同时符合多行，按更保守的建议处理。

| 如果你是这种情况 | 建议 | 为什么 | 注意点 |
|---|---|---|---|
| 第一次养中大型高能犬，但愿意学习训练 | 优先边牧 | 更容易用家庭互动、运动和规则管理接住 | 不要只靠散步消耗 |
| 有工作犬经验，并且目标是护卫、搜救或犬运动 | 可以看马犬 | 高驱动力在专业目标里是优势 | 先找训练资源 |
| 每天只能短遛，时间经常不稳定 | 两个都先别养 | 都不适合低消耗、低互动、低规则生活 | 先看能量更低的犬种 |

越不确定，越应该先按保守建议处理。
```

***

## 十一、行业常识与客观祛魅

评测最后要帮读者拆掉营销话术、行业黑话、短视频种草、参数崇拜和过度承诺。祛魅不是为了刻薄，而是为了校准预期。

可以写：

- 常见宣传哪里夸大。
- 参数、排名、销量、视频效果为什么不能直接等于适合你。
- 低价为什么可能合理，什么时候反而可疑。
- 什么情况需要专业人士，而不是继续看评测。
- 真正容易后悔的地方是什么。

好写法：

```markdown
“聪明”不等于好养。边牧学得快，也会更快学会主人的规则漏洞；马犬看起来帅，也不代表适合普通家庭。

- 短视频展示的是训练结果，不是日常成本。
- “护主”不是天生可靠，缺少训练时可能变成过度防御。
- 成年后的力量、兴奋度和管理难度，比幼犬时期的可爱更重要。
```

不要写成：

```text
总之，适合自己的才是最好的。大家根据自身情况理性选择。
```

***

## 十二、不同意图的写法

### 产品对比

适合“A 和 B 哪个好”“几款怎么选”“哪个更值”。

必须先给倾向结论，但正文不必每次都按“数据口径 → 核心差异 → 场景选择 → 避坑”排。先看用户真正问的比较点，再选路径：

- **强参数横评**：先对齐版本和关键数值，再解释哪些数值会改变选择，最后按场景分流。
- **体验/审美横评**：先回答主观感知，再拆场景、人群、搭配/配置条件，最后写结论反转条件。
- **预算/性价比横评**：先拆价格和隐性成本，再判断加钱值不值、降级会损失什么。
- **长期拥有横评**：先写真正容易后悔的点，再回到现在该怎么选。
- **礼品/排面/社交横评**：先写外界如何感知，再写自用体验和维护成本，避免只看品牌光环。

不要写成：

```markdown
## A 产品介绍
## B 产品介绍
## A 的优点
## B 的优点
## 总结
```

如果对比对象属于强参数产品，至少包含一张“关键参数 + 决策影响”表。不要只写品牌感知、审美判断或泛泛的优缺点。

同样是三款车对比，“谁更有排面”可以用评分模型 + 场景反转；“谁更适合家用”可以用家庭用车场景走查；“谁最不容易后悔”可以从保养、保值、空间和换代风险写起。不能因为都是同一组产品，就复用同一套目录。

### 真假鉴别 / 智商税

适合“是真的吗”“是不是假的”“是不是智商税”“宣传靠谱吗”。

必须覆盖真假倾向、依据、验证方法、风险和购买建议，但顺序要由题目决定：

- 低价真伪题：更适合先拆价格能不能支撑原料，再讲可能的替代形态，最后给实物和标签验证。
- 功效智商税题：更适合先拆原理和证据强弱，再讲哪些宣传偷换概念，最后给适用边界。
- 渠道真伪题：更适合从渠道、票据、批号、包装、卖家历史和售后保障写起。
- 食品安全题：更适合把“真不真材实料”“划不划算”“安不安全”拆开，不要混成一个结论。

例子方向：

- 13 元 8 个鳗鱼寿司：重点看价格是否支持真鳗鱼、是否可能是鳗鱼边角料/替代鱼/调味制品、商家标注。
- 闲鱼精华油：重点看保存、开封、批号、发票、卖家历史、退换保障，不要只说“假货多”。
- 美瞳清洗器注氧：重点看眼部卫生和真实护理价值，不要被“注氧”这种听起来高级的词带走。

### 功效和健康类

涉及药品、医疗器械、保健品、母婴、护肤功效、生发、防脱、减肥、助眠、食品健康或安全防护时，必须更谨慎。

必须做到：

- 不承诺根治。
- 不写“一定有效”。
- 不写“无副作用”。
- 不写“所有人都适合”。
- 写清楚什么前提下才有意义。
- 写清楚哪些人不建议自己试。
- 写出风险信号。
- 告诉用户什么时候该找专业人士。

常见内容：

```markdown
开头：是否有用，以及只对哪部分人有意义。
科普解释：作用机制、适用边界、多久看结果。
场景对号入座：哪些情况可以考虑，哪些情况先就医或咨询专业人士。
客观祛魅：拆“根治”“快速见效”“人人适用”“无副作用”等话术。
```

上面不是固定目录。可以按“适用人群 → 时间线 → 风险信号”写，也可以按“证据强弱 → 使用门槛 → 复盘节点”写；如果用户更关心体验，就把剂型、麻烦程度、坚持成本提前。

### 审美 / 排面 / 高级感

用户问“好不好看”“哪个更有排面”“显不显高级”“是不是奢侈品”时，不要强行转成参数评测。

常见内容：

```text
先正面回答主观判断，但不要绝对化。
说明什么场景下成立。
解释影响观感的关键条件。
给搭配或选择建议。
拆掉品牌/价格/网红图带来的误判。
```

这类文章尤其不要每次都写成“结论、数据、体验、最终建议”。可以按“第一眼观感 → 翻车条件 → 调整办法”写，也可以按“人群气质 → 场合 → 单品细节”写；如果是汽车或腕表这类强品牌物，也可以用“社交感知 → 自用体验 → 长期代价”的顺序。

即使问题很轻，也要拆变量。常用变量：

- 人：年龄、身材、气质、职业、体态、肤色、发型。
- 物：版型、颜色、材质、尺寸、做工、品牌识别度。
- 搭配：鞋、裤长、上衣比例、外套、配饰、妆发。
- 场合：通勤、正式、社交、约会、拍照、家庭场合。
- 风险：显土、显矮、显油腻、过度用力、维护麻烦。

输出要给用户可执行动作：改裤长、换鞋型、换颜色、降低紧身度、加外套、选替代版型等。

好写法方向：

```markdown
47 岁男性可以穿大裤脚牛仔裤，但关键不是年龄，而是裤长、鞋型和上衣比例。裤脚太堆、鞋子太薄、上衣太宽，就容易显得拖沓；如果裤长干净、鞋底有厚度、上衣利落，反而会显得松弛。
```

### 使用保养

用户问“能不能泡水”“噪音大吗”“怎么洗”“会不会坏”时，重点不是写产品优缺点，而是写使用边界。

常见内容：

```text
结论：能不能 / 正常不正常 / 建议怎么做。
边界：什么程度可以，什么程度不建议。
原因：材料、结构、工作方式或损耗机制。
操作：正确做法。
风险：错误使用的后果。
```

### 性能兼容

用户问“能不能玩”“够不够用”“配置行不行”时，不要只回答能/不能，要说明体验档位。

常见内容：

```text
结论：能不能运行。
体验档位：低画质/中画质/高画质，大概适合什么预期。
限制：分辨率、帧率、内存、驱动、散热、版本。
建议：该调什么设置，或者是否该换方案。
```

### 泛泛问“怎么样 / 可以吗”

如果产品对象明确但需求不明确，不要只问用户补充，也不要硬给单一结论。先给一个有边界的默认判断，再用“你更像哪类用户”展开：

```text
默认倾向：在 A 前提下可以 / 不建议。
可能反转：如果你更重视 B，结论会变。
关键变量：价格、场景、频率、风险、替代方案。
下一步：先确认哪 2-3 件事。
```

## 十三、不同品类的评测重点

### 数码家电 / 办公设备

重点看：

- 性能是否覆盖用户任务
- 兼容性和生态限制
- 稳定性、噪音、发热、功耗
- 耗材、维修、维护成本
- 长期使用成本，而不只是购买价
- 新手上手难度、安装空间、售后和保修。
- 同价位替代方案，以及是否该加钱上一级或降级省钱。

适合题目：喷墨 vs 激光打印机、Intel ARC 能不能玩游戏、光伏逆变器噪音、电子钢琴 88 键。

### 美妆护肤 / 生发防脱 / 美瞳护理

重点看：

- 成分或技术原理
- 证据强弱和预期效果
- 适合肤质、屏障状态、敏感风险
- 使用频率和叠加冲突
- 眼部和接触类产品的卫生风险
- 宣传是否夸大
- 起效时间、复盘节点、停用后会怎样。
- 谁应该先咨询医生 / 药师 / 皮肤科，而不是自己试。

写这类时，必须区分“可能有效”“适合你”“值得买”三件事。

### 食品饮品 / 营养品 / 酒水

重点看：

- 配料表和原料真实性
- 价格是否支持宣传的原料
- 口味、营养、安全和添加剂
- 是否适合长期吃/喝
- 传言是否偷换概念或制造恐慌
- 目标人群：减脂、控糖、儿童、老人、运动、送礼、入门尝鲜。
- 食用频率和替代选择：偶尔吃、日常吃、是否有更便宜或更健康替代。

规则：要把“不高级”“不划算”和“不安全”分开，不要混成一个结论。

### 服饰鞋包 / 户外装备

重点看：

- 年龄、身材、气质和场景适配
- 版型、颜色、材质、舒适度
- 搭配难度和保养方式
- 品牌定位与社会认知
- 户外功能材料的使用边界
- 具体穿法：鞋型、裤长、上衣比例、外套长度、配饰。
- 翻车点：显矮、显胖、显油腻、太用力、像工装/校服/销售制服。

用户问始祖鸟冲锋衣能不能泡水时，要区分淋雨、防水膜、浸泡清洗、洗涤剂和 DWR 表层维护。

### 家居日用 / 厨房用品 / 材料

重点看：

- 日常效果
- 清洁和维护难度
- 耐用性和替换成本
- 舒适性、效率和家庭使用频率
- 材料差异带来的真实体验
- 家庭成员差异：老人、小孩、宠物、小户型、租房、重度使用。
- 收纳、噪音、耗材、安装、清洁死角。

不要只说“超纤皮更好”，要说明它好在哪里：耐磨、手感、透气、成本、维护还是观感。

### 汽车出行

重点看：

- 预算和使用场景
- 品牌认知、面子和社交信号
- 驾驶感、空间、舒适、NVH
- 油耗/电耗、保养、维修、保值率
- 新车/二手车风险
- 如果我是车主：通勤、接客户、带家人、停车、长途、高速、雨雪路况分别会怎样。
- 高低配和同品牌上一级是否值得加钱。

用户问“哪个更有排面”时，先回答社会感知，再补充实际用车取舍。

汽车横评必须补充客观数值。最低要求：

- 对比版本：写清楚具体车款或配置级别，避免拿一台高配打一台低配。
- 价格：官方指导价；终端优惠只有在有可靠来源且标注地区 / 时间时才写。
- 尺寸空间：长宽高、轴距；解释它对后排、气场或停车便利的影响。
- 动力和能耗：最大功率、峰值扭矩、零百加速、驱动形式、WLTC / CLTC 油耗或电耗。
- 配置和质感：座椅、音响、灯光、辅助驾驶、屏幕、内饰材料；只写会影响体验和排面的配置。
- 生命周期：是否临近换代、是否已有同门新车、二手保值和后续新鲜感风险。

如果主题是“排面”，可以建立一个主观评分模型，但必须说明它是判断工具，不是事实排名。建议权重：

```text
品牌社会识别度 30%
外观气场和车身尺寸 20%
内饰豪华感 20%
配置完整度 10%
动力和车型级别感 10%
新鲜感 / 换代风险 10%
```

评分后必须写清边界：商务 / 长辈场景、年轻社交场景、自己驾驶场景、低调通勤场景的结论可能不同。

### 宠物

重点看：

- 主人经验
- 居住空间和时间预算
- 运动量、训练需求和性格
- 家庭安全、社区限制和医疗成本
- 新手能不能接住、每天时间预算、长期护理和医疗开销。
- 最坏情况：扰民、拆家、攻击风险、弃养风险。

高驱动力犬不能只写“聪明”“帅”“服从性好”，必须写管理成本。

### 保险 / 收藏 / 二手 / 真伪

重点看：

- 核心风险和最坏损失
- 渠道、票据、批号、包装、保存状态
- 市场价格和流动性
- 隐性条款、除外责任、续保条件
- 是否需要专业鉴定或顾问
- 最坏损失、退出难度、流动性、维权成本。
- 验证路径：票据、批号、包装、渠道、检测、合同条款。

保险不要按产品名硬推荐，要先看保障责任、健康告知、免赔额、续保、理赔场景和预算。

### 工业设备

重点看：

- 物料和工艺目标
- 产能、能耗、精度和稳定性
- 易损件、维护、安全和培训
- 场地条件和总成本

缺少物料、产能、预算、工艺目标时，先问，不要硬选。

## 十四、标题怎么写

标题要服务阅读逻辑，不要照搬功能名。

可以写：

```markdown
## 真正拉开差距的是长期维护
## 先看你是哪种使用场景
## 别被“高浓度”和“快速见效”带偏
```

不要每篇都写：

```markdown
## 先说结论
## 适合谁
## 不适合谁
## 优点
## 缺点
## 总结
```

标题原则：

- 标题数量按复杂度决定。简单问题可以 2-4 个；具体产品横评、健康功效、高客单价购买建议可以更多，但每个标题都要服务一个真实判断。
- 标题要具体到本题，不要像通用字段。
- 不要每篇复用同一套标题，只替换产品名。
- 不要让连续几篇评测呈现相同骨架。即使都要“先给结论”，正文也要根据题目换入口、换主线、换标题语气。
- 不要把所有标题都写成金句。
- “适合谁 / 不适合谁 / 优缺点”可以出现，但不要机械平铺成整篇目录。

### 标题层级要有主次，不要全篇平铺

产品评测越长，越需要先规划目录层级。不要把每个分析点都写成同级一级标题，否则文档会像字段清单，读者看不出判断路径。

默认层级：

- **一级标题**：只放 3-5 个大模块，承载决策阶段或核心问题群。
- **二级标题**：放每个模块下的具体分析点，例如机制、参数、体验、场景、风险、替代方案。
- **三级标题**：只在正式报告、长横评或复杂高风险主题里少量使用；如果二级标题已经能讲清，不要继续下钻。

一级标题应该回答“这一大段在帮用户完成哪一步决策”，二级标题才回答“这一小节具体分析什么”。写标题前先做一次“结构变体选择”：

1. 先写出一句本文主矛盾，例如“低价能不能支撑真鳗鱼”“有效不等于适合所有脱发”“排面取决于场景感知而不是车标单项”。
2. 再选择一条主线：证据链、价格拆解、人群分流、场景走查、时间线、误区校正、红黄绿灯或评分模型。
3. 最后把主线拆成 3-5 个一级标题。不要直接把“结论 / 数据 / 体验 / 建议”当标题。

常见一级模块可以是：

```text
先判断是否适合你
核心差异和真实体验
风险、代价和长期维护
按场景做最终选择
```

这些只是抽象功能，不是标题模板。换题时不能复制示例标题，而要先做三步：

1. **抽象用户真正的问题**：是在问管不管用、哪个更好、值不值得买、真假智商税、是否适合某人、怎么保养，还是有没有排面。
2. **把信息分组成 3-5 个决策阶段**：可以先判断前提，也可以先拆价格、先讲误区、先按人群分流或先做场景走查。不要固定为“先判断 → 再分析 → 看风险 → 做选择”。
3. **再把决策阶段改写成本题自己的标题**：标题里要出现本题的对象、场景或关键矛盾，而不是只写“适合谁 / 风险 / 总结”。

可以按意图套用“层级思路”，但不要套用标题原文：

| 题目类型 | 一级标题通常承载什么 | 二级标题通常展开什么 |
|-|-|-|
| 功效 / 健康 / 安全类 | 是否适合你、证据边界、风险和长期管理 | 机制、适用人群、起效时间、副作用、谁先别用、替代方案 |
| 多产品对比 | 先给倾向结论、数据口径、核心差异、场景选择 | 版本价格、关键参数、体验差异、长期成本、结论反转条件 |
| 值不值得买 | 购买前提、真实体验、成本代价、替代选择 | 预算、使用频率、功能是否过剩、维护成本、买前确认 |
| 真假 / 智商税 | 结论倾向、原理拆解、验证路径、风险处置 | 宣传哪里真、哪里夸大、怎么查证、最坏损失、避坑渠道 |
| 审美 / 搭配 / 排面 | 主观结论、成立场景、影响观感的变量、怎么调整 | 人群气质、版型颜色、搭配细节、场合、翻车点 |
| 使用 / 保养 / 维护 | 能不能这样用、边界条件、正确操作、错误后果 | 材料结构、可承受程度、清洁步骤、损耗风险、补救方式 |
| 性能 / 兼容 | 能不能满足任务、体验档位、限制条件、升级建议 | 配置参数、画质帧率、接口生态、散热功耗、替代方案 |

如果题目很短，也要先抽象成上表里的某一类或几类，再决定标题层级。比如“这件冲锋衣能泡水洗吗”不是写成“优点 / 缺点 / 总结”，而应该围绕“能不能泡、为什么、怎么洗、洗坏的风险”分层；“45 岁男的穿小脚裤怎么样”不是写成“适合 / 不适合”，而应该围绕“默认观感、成立条件、身材和搭配变量、替代版型”分层。

下面的例子只说明“同一类内容可以有不同结构”，不要复制为固定模板。

“米诺地尔生发液真的管用吗”至少可以有两种走法：

```markdown
## 一、先把“管用”说清：它帮的是哪一类脱发
### 1. 头顶、发缝慢慢变稀，和突然大把掉发不是一回事
### 2. 有效不等于人人该用，也不等于越早越猛越好

## 二、按时间线看：什么时候该坚持，什么时候该复盘
### 1. 前几周别急着判失败
### 2. 几个月后还没有变化，要重新判断脱发类型和用法

## 三、真正劝退人的不是价格，而是长期使用门槛
### 1. 刺激、油腻、坚持成本和停用预期
### 2. 哪些情况先别自己硬试

## 四、买前最后判断：你属于值得试的那类吗
### 1. 自查脱发信号
### 2. 该试、该问诊、该换方案分别怎么选
```

也可以写成更偏人群分流：

```markdown
## 一、三类人先分开：能试、先观察、先问专业人士
## 二、别被“生发”两个字带偏：它解决不了所有掉发
## 三、使用门槛到底高不高：剂型、频率和复盘节点
## 四、如果我是不同脱发阶段，会怎么做决定
```

“奔驰 C260、宝马 3 系和奥迪 A4 哪个更有排面”也不只有一种结构：

```markdown
## 一、先把“排面”拆成三种场景
### 1. 接客户和长辈场景，看的是稳重和品牌识别
### 2. 年轻社交场景，看的是运动感和新鲜感
### 3. 自己开得爽不爽，会反过来影响长期满意度

## 二、别只看车标：版本、尺寸和内饰会改变观感
### 1. 同品牌低配和高配，排面差距可能比品牌差距还明显
### 2. 轴距、动力、灯光和座舱质感分别影响什么

## 三、三台车的排面画像：谁更像哪种人
### 1. C260 更偏精致和体面
### 2. 3 系更偏年轻和驾驶
### 3. A4 更偏低调和性价比

## 四、结论怎么反转：预算、配置和用车对象比一句排名更重要
```

同一题也可以用评分模型结构：

```markdown
## 一、先给主观评分口径：排面不是事实排名
## 二、按品牌识别、外观气场、内饰质感和新鲜感分别打分
## 三、分数之外的现实：保值、维修和换代风险
## 四、按商务、家用、自己开重新排序
```

“鳗鱼寿司 13 元 8 个是真鳗鱼吗”不要固定写成“真假倾向 / 价格 / 验证 / 购买建议”，也可以换成：

```markdown
## 一、13 元先拆账：这份寿司的钱到底够不够给鳗鱼
## 二、真鳗鱼也分很多种：整片、边角料、调味制品和替代鱼
## 三、拿到手怎么判断：先看标注，再看纹理和厚度
## 四、便宜可以吃，但要避开这几类不透明商品
```

或：

```markdown
## 一、先分三档：可信、存疑、先别买
## 二、为什么低价不一定等于假，也不等于好
## 三、商品名和配料表里最关键的几个字
## 四、如果只是想解馋，怎么把风险降到最低
```

不要这样组织：

```markdown
## 一、它到底对哪类脱发更有意义
## 二、机制和证据边界
## 三、多久见效
## 四、浓度和剂型
## 五、适合人群
## 六、风险副作用
## 七、营销话术
## 八、替代方案
## 九、使用清单
## 十、最终建议
```

上面这种目录虽然信息不少，但全部同级，读者会觉得每一节都一样重要，文档也缺少阅读节奏。另一种也要避免：每篇都写成“四个大模块 + 每个模块 2-3 个小点”的同构目录。层级清楚不等于结构固定；自由不是乱写，而是让标题顺序贴着本题的判断路径走。

## 十五、结构化 block 怎么用

结构化 block 是为了帮助判断，不是为了显得丰富。

### callout

- 推荐只用 1 个开头结论高亮。
- 高风险主题可以再加 1 个风险提醒。
- 不要每节都用高亮块。

### 表格

- 适合放在场景化选择部分。
- 表格数量按内容复杂度决定。简单审美题可以不用表；具体评测通常至少需要场景表，强参数产品还需要参数表；高风险产品还可以增加风险/时间线表。
- 不要让表格替代解释。
- 强参数产品可以有 2 张表：一张关键参数表，一张场景选择表。参数表必须带“对结论的影响”或在表后解释。

### 清单

- 适合放在结尾，帮助用户买前确认。
- 清单要具体，不要写“结合自身情况”“理性选择”。

### 画板 / 流程图

- 只有分支很多、纯文字会看不清时才用。
- 3-5 行文字能讲清楚，就不要插画板。

***

## 十六、禁止事项

不要：

- 用产品历史、定义、品牌背景开头。
- 用“从多个维度分析”开头。
- 用“没有绝对好坏”“因人而异”“适合自己的才是最好的”当作结论；可以承认边界，但必须给倾向判断。
- 平均分配篇幅介绍双方优缺点。
- 只说适合谁，不说谁应该放弃。
- 只罗列参数，不解释对决策有什么影响。
- 完全不列参数，却对汽车、数码、家电、工业设备这类强参数产品下结论。
- 把不同版本、不同配置、不同年份的参数混在一起比较。
- 把主观评分写成客观事实排名，或不给评分权重。
- 只给结论、表格和清单，不解释为什么。
- 因为用户问题很短，就把复杂产品写成浅显短答。
- 因为用户没给完整背景，就替用户绝对决定；应该给条件化结论和验证路径。
- 每个品类都套同一套评测角度，忽略品类差异。
- 让表格替代科普解释。
- 把必须交代的信息逐个升成一级标题，写成字段清单。
- 长文档里所有章节都用一级标题，导致目录没有主次。
- 一级标题只是“机制 / 时间线 / 风险 / 清单”这类字段名，而不是决策模块。
- 二级标题缺失，导致具体分析点和大模块混在同一层。
- 把四段逻辑的功能名直接复制成固定标题。
- 每篇都用同一套标题，只替换产品名或对象名。
- 连续几篇评测都写成相同的四段式或五段式目录，即使标题文字略有变化。
- 为了规整而牺牲题目自身的叙事路径；内容应该像本题自然长出来，而不是像表单填空。
- 编造价格、排名、销量、用户评价、奖项、实测结果、个人体验或专家背书。
- 在用户没有提供依据时写“我实测”“用了三个月”“很多用户反馈”“销量很高”“全网口碑很好”“医生都推荐”。
- 结尾只写“理性选择”“按需选择”“根据预算决定”。

***

## 十七、改写已有评测

如果用户给了已有评测，让你润色、改写、扩写或压缩，按这个顺序处理：

1. 把判断移到第一段。
2. 删除不影响购买决策的背景。
3. 判断它属于即时结论、短评测导购还是正式报告。
4. 判断用户意图和产品品类。
5. 补上谁可以买、谁先别买、什么情况下结论会反过来。
6. 把空话改成“判断 → 依据 → 边界 → 行动”。
7. 按具体程度补充展开：具体产品补横向/纵向/参数/体验/成本；不具体问题补变量、场景和搭配/使用条件。
8. 如果是强参数产品，先补齐关键参数表和数据口径；如果原文只有参数表，再增加场景选择表。
9. 补上“如果我是不同用户，我会怎么选”的路径。
10. 补上最大短板、代价或风险。
11. 补上行业常识、营销祛魅或错误预期提醒。
12. 删除没有依据的实测、销量、排名、评价和个人体验。
13. 重排标题层级：把大模块保留为一级标题，把机制、参数、体验、风险、清单等具体分析点降为二级标题，避免全篇同级平铺。
14. 检查目录是否像最近几篇评测的套壳；如果只是“结论 / 数据或原理 / 体验或风险 / 最终建议”的换皮，重新选择叙事路径。

***

## 十八、输出前自检

结束前默默检查：

- 开头是否直接给结论？
- 结论是否有边界，而不是替用户绝对决定？
- 是否判断了回答深度、用户意图、品类和风险？
- 是否根据产品具体程度展开到足够深，而不是浅答？
- 是否按品类选择了不同评测角度，而不是套模板？
- 是否先选择了叙事路径，而不是直接套“结论 / 数据 / 体验 / 风险 / 建议”？
- 如果最近连续生成过类似文档，这篇的正文入口、一级标题和阅读顺序是否明显不同？
- 如果是强参数产品，是否核对了版本、价格、关键参数和整理日期？
- 是否把参数写成“数值 + 对结论的影响”，而不是只堆数据？
- 低风险问题有没有写得足够直接？
- 高风险问题有没有写清边界、风险和验证方法？
- 每个关键判断是否有依据、边界和行动建议？
- 用户能不能在场景表或人群分组里对号入座？
- 有没有行业常识、客观祛魅或营销话术拆解？
- 适合和不适合人群是否具体？
- 是否解释了最大短板、代价或风险？
- 是否写了使用体验、长期成本、壁垒经验或下一步验证路径中至少一部分？
- 如果用了评分模型，是否写清权重、主观边界和适用场景？
- 标题是否具体到本题，而不是字段罗列？
- 长文档是否有清晰标题层级，而不是所有章节都用一级标题？
- 一级标题是否是决策模块，二级标题是否是具体分析点？
- 标题层级是否有主次，但没有机械变成“四个大标题 + 每节两三个小标题”的固定壳？
- 有没有为了显得丰富而强塞画板、高亮块或表格？
- 结尾有没有具体下一步？
- 有没有编造实测、销量、口碑、专家背书或最新价格？

## 十九、飞书格式差量

- **参数/对比/评分表格是正当产物**：关键参数表、横向对比表、场景选择表、评分模型表是产品评测支撑决策的核心 block，属正当使用，全局克制红线不针对它们。强参数产品（车 / 数码 / 家电 / 工业设备）可有 2 张表（关键参数表 + 场景选择表），参数表须带"对结论的影响"列或在表后解释。
- **红黄绿灯标注按需正当**：风险等级清晰、用户想快速避坑时，用可以买 / 谨慎 / 不建议三档承接（红黄绿灯路径）是正当的分流手段，可配合颜色或标签表达。
- **callout 克制**：开头结论卡建议只用 1 个高亮块；高风险主题可再加 1 个风险提醒。不要每节都套高亮块。
- **正当≠堆砌**：表格数量按内容复杂度决定——简单审美题可以不用表，只用分组段落；表格不能替代科普解释；画板/流程图只在分支很多、纯文字看不清时才用，3-5 行文字能讲清就不插。任何不服务判断、只为"显得丰富"的 block 都要删掉。
