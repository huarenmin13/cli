# 去 AI 化 & 口语化技法库(Anti-AI / Make It Human)

这是讲稿和普通 AI 文本的**分水岭**。初稿写完,对照本文件逐项清洗。
核心心法一句话:**写完之后大声念出来。凡是念着拗口、说着像念稿、听着像放之四海皆准的废话,就是病灶。**

讲稿的"人感"不是靠堆形容词堆出来的,而是靠**短句、口语连接、具体细节、节奏起伏、留白**做出来的。

---

## 一、AI 味黑名单:见到就删 / 改写

AI 最爱写的"安全废话",正确率高但毫无信息量,听众一秒出戏。看到这些立刻处理:

**万能套话**(删掉,换成具体的):
"在这个特殊的日子里" / "让我们共同期待美好的未来" / "相信在大家的共同努力下" / "具有重要的意义" / "起到了积极的作用" / "营造良好的氛围" / "我感到无比荣幸和激动"。

**书面连接词**(口语里没人这么说,换掉):
"基于" → "就因为 / 说到底";"鉴于" → "考虑到 / 因为";"综上所述" → "说了这么多,其实就一句话";"此外 / 另外" → "还有件事 / 不光这样";"值得注意的是" → "这里有个事得提一句";"众所周知" → 直接删(既然众所周知就别说了)。

**头重脚轻的状语**:"在……的过程中""在……的背景下""通过……的方式"——这些套壳能拆就拆,直接说事。

**对仗强迫症**:连续三四组工整的"不是……而是……""既要……又要……"会变成催眠口诀。排比是调味料不是主食,**一篇讲稿里高密度排比段最多 1-2 处**,且要用在情绪高点。

---

## 二、僵化大段 → 有呼吸的短句

AI 爱写一句话套三个从句的长复合句。**讲稿里一句话超过 40 个字,听众的耳朵就跟丢了。**

把长句"剁碎":找到句子里的连接词和逗号,能断就断成独立短句。

> ❌ 在当前市场竞争日益激烈、用户需求不断升级的背景下,我们通过持续的技术创新和精细化的运营管理,实现了用户规模和营收的双增长。
>
> ✓ 市场越来越卷,用户的胃口也越来越高。(停顿) 怎么办?我们就干两件事:把技术做硬,把运营做细。结果呢?用户翻倍,收入也翻倍。

注意上面的改写做了什么:拆短句、加口语词("卷""胃口")、加自问自答、加停顿标注、把抽象变具体。

## 三、"说人话"的五个技巧

口语化不是无差别地"加词"，而是**先认讲者是哪种笔法，再决定动作的力度**。同样一个动作，企业家、主持人、网红主播的尺度完全不同。下面每个动作都标了分场景的尺度。

**1. 加"嘴巴词、口癖"**——书面语里没有、但人一开口必然带的词，去"念稿味"最快的一招。分两步用：先从词库里认识有哪些货，再按笔法决定能拿哪些、拿多少。

第一步，认识口癖词库（按功能分四类）：

- 语气助词（句尾松气，让句子落地不僵）：啊、呢、嘛、吧、呀、哈。

- 口头开场词（起句的自然引子，把注意力领进来）：其实、说白了、说到底、讲真、你看、你想啊、我跟你讲、怎么说呢、不瞒你说。

- 互动确认词（向听众递个眼神，制造对话感）：对吧、是不是、有没有、知道吗、你懂的、对不对。

- 程度／转折口语词（替换书面的"非常／然而／但是"）：特别、贼、老、压根、其实吧、话又说回来、可问题是。

第二步，按笔法决定取用尺度——**这是关键，不同讲者嘴里的口癖天差地别**。创始人像直播主播一样喊"家人们扣个 1"会塌人设，网红说"现将情况说明如下"没人看：

- 笔法 B · 商业说客（发布会、路演、峰会、带货）：四类都能用，越往带货越放开。峰会／发布会重开场词和互动词（说白了、你想啊、关键在于、是不是）；直播带货火力全开，外加专属高能词（听我说、记住了、划重点、冲就完了、家人们、姐妹们）。示例（发布会）："说白了，我们就解决一件事——让它更快。"／示例（带货）："听我说姐人们，这个价格真的，错过今天就没了。"

- 笔法 C · 共情叙事者（婚礼、毕业、年会、悼词）：取温的、真的，落在情绪和回忆上。温情场景用走心开场词（你知道吗、说真的、我一直记得、说起来）；主持／年会可放热，加互动词（来、咱们、好不好、掌声在哪里）；悼词最克制，几乎不用口癖，只留"我常想起""说起来"这类轻引子，靠留白托情绪。示例（婚礼）："说真的，我第一次见这孩子，还是他追着她跑那年。"

> 取用原则：一段点缀一两个就够，让它落在自然的呼吸停顿处，别机械往每句尾巴上挂。大声念——顺就对，油腻、刻意、或"这人不可能这么说话"就是错，删掉。

**2. 自问自答**——把陈述句变成"提问 + 回答"，制造对话感和悬念。B/C 笔法可以跳脱、更口语（"猜猜结果怎么着？(停顿) 翻了一倍。"）。

**3. 用"你／我们"而不是"大家／各位"**——拉近距离。"各位可能会有这样的疑问"不如"你可能在想"。注意分场景：B（带货、峰会）、C（婚礼、毕业）大胆用"你"，一对一说话感最强；团队年会、内部分享可多用"我们／咱们"建立共同体。

**4. 第二人称代入场景**——"是不是经常遇到这种情况……"比客观描述更抓人。这招在 B 笔法（带货痛点、产品演示）和 C 笔法（年会、婚礼、毕业共鸣）威力最大；但要按讲者身份控制热度，创始人、长辈、主持人都不能说成同一种网感。

**5. 具体名词替换抽象概括**——这是去 AI 味最猛的一招，且**所有笔法通用、没有例外**：
"我们取得了显著成绩" → "去年这时候我们才 3 个人挤在一间小会议室，现在整整一层楼坐不下了"。
"他工作认真负责" → "他办公室的灯，是整个楼最后一个灭的"。

## 四、Show, Don't Tell(情感类必用)

不要"告诉"听众该有什么情绪,要"展示"一个画面让他们自己生出情绪。形容词是廉价的,细节是昂贵的。

> ❌ 他是一个非常无私奉献、深受大家爱戴的好人。
>
> ✓ 他抽屉里常年放着速效救心丸,但谁家孩子上学有困难,他第一个掏钱。

> ❌ 这对新人非常恩爱,感情很好。
>
> ✓ 他俩异地三年,他手机里存着两个时区的天气,她那边下雨,他这边就提醒她带伞。

写情感稿时反复问自己:**我能不能把这个形容词,换成一个能拍成画面的细节?**

## 五、节奏与留白

讲稿是有"鼓点"的。全程一个节奏会让人困。

**长短交替**:几个短句快速推进后,来一个稍长的句子舒展一下;情绪高点用一串短促的排比,然后**戛然而止留一个停顿**。

**敢用停顿**:在金句前、转折处、情绪重锤前,标 `(停顿)`。停顿是讲稿的标点,给听众反应时间,也给金句留出回响的空间。AI 稿最大的问题之一就是"满"——一刻不停地输出,不给耳朵留缝。

**单句成段**:最重要的那句金句,单独成段、前后留白,让它在视觉和听觉上都"孤立"出来,分量自然就重了。

---

## 六、人设一致性校验

最后一遍:把稿子放到讲者嘴里"试穿"。

企业家:自信、有故事,可以金句,别像念行业白皮书。
网红主播:极度口语、高能量、密集互动。
学生/青年:真诚、可以自嘲,绝不爹味说教。
长辈(婚礼/家宴):温厚、克制,细节走心。

凡是"这个人不可能这么说话"的句子,重写。
