# 场景精细划分(Scenario Map)

定标完成后先读本文件,找到最匹配的场景,照搬它的「语态 + 默认篇幅 + 结构模板 + 踩雷点」。
跨场景混合时,以主笔法为骨架、借另一种笔法的技法(例:企业家峰会演讲 = B 路子的结构 + C 路子的故事开场)。

---

## 笔法 B · 商业说客 旗下场景

### B1 产品发布 / 主题演讲(Keynote)
- **听众**:媒体、用户、行业。**语态**:自信、有张力、制造期待。
- **默认篇幅**:10-30 分钟,按 PPT 节奏分段。
- **结构**:黄金 3 秒抛痛点/反差 → 旧世界的问题 → 我们的方案(功能落到场景,不堆参数)→ 一个 Demo 高潮 → 价格/上市的"还有一件事"。
- **踩雷点**:忌平铺直叙念参数;每个功能要翻译成"对用户意味着什么";要设计 1-2 个记忆锚点(金句或数字)。

### B2 路演 / 融资 Pitch
- **听众**:投资人。**语态**:极致高效、数据硬、逻辑闭环。
- **默认篇幅**:5-15 分钟,严格踩 BP 翻页。
- **结构**:一句话讲清你是谁 → 市场多大痛点多痛 → 解决方案 → 数据/增长 → 团队 → 要多少钱干什么。
- **踩雷点**:开口 30 秒内必须让人听懂你做什么;忌讲情怀不讲数字;每页停留有节奏提示。

### B3 直播口播 / 带货话术
- **听众**:直播间观众/冲动消费者。**语态**:极度口语、高频互动、紧迫感。
- **默认篇幅**:按单品 1-5 分钟话术循环。
- **结构**:拦截("先别划走")→ 痛点共鸣 → 产品亮点(人话讲卖点)→ 信任背书 → 价格锚点与降价节奏 → 催单逼单(限时/限量)。
- **踩雷点**:句子要短到能一口气喊出来;多用"家人们""听我说""记住了";制造稀缺和紧迫;忌长句忌专业术语。

### B4 行业峰会 / 论坛发言
- **听众**:同行、潜在客户、媒体。**语态**:专业但不端着,有观点有金句。
- **默认篇幅**:8-20 分钟。
- **结构**:一个反直觉观点开场 → 行业趋势判断 → 自家实践佐证 → 给行业的呼吁。
- **踩雷点**:要有可被引用的"观点金句";忌变成公司广告(借势用 C 路子讲个故事更高级)。

## 笔法 C · 共情叙事者 旗下场景

### C1 婚礼致辞(新人/父母/证婚人/主持)
- **听众**:宾客、新人。**语态**:温暖、真诚、有细节、适度幽默。
- **默认篇幅**:父母/证婚 4-6 分钟;主持串词另算。
- **结构**:一个关于新人的具体小故事/细节 → 祝福与嘱托 → 升华到爱与陪伴。
- **踩雷点**:用细节代替"郎才女貌天作之合"等套话;敬称和称呼别错;父亲致辞要克制不煽情过度。

### C2 晚会 / 年会主持串词
- **听众**:现场观众。**语态**:热烈、流畅、承上启下。
- **默认篇幅**:按节目单逐段。
- **结构**:见 formats.md 的"主持串词"格式(开场词 / 节目串场 / 互动环节 / 结束语)。
- **踩雷点**:串场要自然衔接上下节目,给个理由/情绪过渡,不能硬切;报幕信息(节目名、表演者)零差错。

### C3 毕业致辞 / 开学致辞
- **听众**:学生(青年)。**语态**:平视、共情、真诚,**坚决拒绝爹味说教**。
- **默认篇幅**:5-10 分钟。
- **结构**:一个真实的、有点自嘲或意外的故事开场 → 几个想送给他们的"不正确但真实"的话 → 祝福与放手。
- **踩雷点**:别端着讲大道理;别堆"未来是你们的"套话;用具体的、带点缺憾的真实经验代替成功学。

### C4 颁奖典礼 / 表彰致辞
- **听众**:获奖者、观众。**语态**:荣耀感、画面感、把功劳讲具体。
- **默认篇幅**:5-10 分钟。
- **结构**:颁奖的意义 → 具体讲获奖者做了什么了不起的事(细节)→ 致敬与号召。
- **踩雷点**:把"贡献突出"换成具体事迹;荣誉要给得有分量。

### C5 祝酒词 / 答谢辞 / 欢迎辞
- **听众**:宾客、合作方、团队。**语态**:真诚、热络、得体。
- **默认篇幅**:5-8 分钟,宜短。
- **结构**:感谢/欢迎缘由 → 一句走心的话或小细节 → 举杯/祝愿。
- **踩雷点**:短就是好;忌一上来报一长串名字和头衔;祝酒落到一个具体的祝愿上。

### C6 悼词 / 追思
- **听众**:亲友、同事。**语态**:哀而不伤、克制、真挚。
- **默认篇幅**:3-8 分钟。
- **结构**:沉痛起 → 回顾生平(用几个能体现其为人的具体片段)→ 寄托哀思 → 安慰生者。
- **踩雷点**:用具体的小事体现人格,不空喊"德高望重";语气克制,留白比煽情更有力量;生平信息准确。
