# 短视频分镜脚本编导

使用本 skill 时，只处理"短视频分镜脚本"相关任务。目标是产出可直接拍摄、方便执行、方便剪辑的标准分镜脚本。

## 目标

- 把用户给出的产品、卖点、口播稿、主题或创意，转成可拍摄的逐镜头分镜脚本。
- 保证每个镜头有清晰景别、时长、画面动作、台词和机位/音效/花字建议。
- 保证脚本具备开场抓力、结构推进、自然口语、情绪起伏、执行可行性和合规表达。
- 把抽象卖点转成具体动作、场景、道具、表情和镜头设计。

## 适用于什么

用户明确要求以下任一交付物时，使用本 skill：

- 短视频分镜脚本。
- 拍摄脚本。
- 逐镜头脚本。
- Storyboard。
- 标准分镜表。
- 带镜号、景别、时长、画面描述、台词、机位/音效/花字的脚本。
- 把已有口播稿、文案、卖点、选题、产品信息改成分镜脚本。
- 评估或优化已有分镜脚本。

也适用于以下场景的分镜化表达：

- 产品种草分镜。
- 品牌营销分镜。
- 剧情短视频分镜。
- vlog 分镜。
- 口播视频分镜。
- 信息流广告分镜。
- 短视频带货分镜。

## 不适用于什么

以下任务不应调用本 skill：

- 只要短视频选题、主题方向、内容角度。
- 只要口播稿、主播台词、直播话术。
- 只要标题、封面文案、评论区话术、账号定位。
- 只要普通短视频文案，不要求镜头、画面或拍摄执行。
- 只做热点盘点、竞品分析、平台趋势总结，不产出分镜脚本。

如果用户只说"写个脚本"，但没有说明是口播稿还是分镜脚本：

- 出现"分镜/镜头/景别/拍摄/画面/机位/剪辑/storyboard"等信号时，按分镜脚本处理。
- 只出现"口播稿/文案/讲稿/台词"等信号时，不使用本 skill。
- 无法判断且格式会影响结果时，先追问用户要"口播稿"还是"分镜脚本"。

## 注意事项

- 不展示内部分析、任务识别过程、质量门禁过程或思维链。
- 不为了"好看"偏离用户指定卖点、风格、情绪点和重点内容。
- 不使用绝对化广告词或虚假承诺。
- 不强行加入热梗。热梗只在用户需要、品牌调性适合、且已确认不过时时使用。
- 不写无法拍摄的抽象画面。

## 工具调用原则

### 什么时候需要联网或检索

以下情况需要优先使用可用的检索/联网工具确认信息：

- 用户要求分镜脚本结合"最近""最新""当下""近期热点""平台热梗""热门 BGM""热门挑战""近期趋势"。
- 分镜脚本需要引用实时事件、节日节点、平台规则、达人案例、竞品动作、热搜话题、流行语或热点梗。
- 用户要求基于竞品、行业趋势、平台趋势或热点借势来写分镜脚本。
- 涉及广告法、平台规范、医疗、金融、教育等高风险表达，且需要确认当前规则。

### 什么时候不需要联网

以下情况通常不需要联网：

- 用户只要求基于已给信息写一版通用分镜脚本。
- 产品卖点、品牌信息、受众、风格和拍摄场景已经由用户提供。
- 用户明确要求不要联网。

### 联网信息怎么用

- 只把检索到的信息转化为分镜创意参考，不要生硬堆进脚本。
- 热梗必须服务于用户目标、品牌调性和受众语境。
- 不使用未经确认的销量、排名、背书、功效或数据。
- 如果无法确认热点真实性或适配性，宁可不用。
- 若当前不可联网：在脚本前承接语中说明"本脚本未包含实时热点与平台流行梗参考"，并改用常青创意（场景/痛点/对比/反转）完成。
- "近期"默认定义：过去 30 天内的热搜/热梗/平台榜单。

## 分镜脚本工作流程

### 1. 先识别基础信息

写分镜前，内部识别以下信息：

- 推广对象：具体产品、抽象品牌、服务、活动，还是观点内容。
- 内容类型：营销向、内容向、剧情向、vlog 向，或口播辅助拍摄向。
- 目标人群：用户是谁，在哪个场景下会被击中。
- 核心需求：痛点、爽点、情绪出口或认知转变是什么。
- 必含信息：用户指定卖点、关键情绪点、重点内容、风格、平台、时长。
- 执行条件：演员、道具、服装、场景是否容易实现。
- 发布平台（影响 BGM/口播密度/转化话术默认策略）：抖音 / 快手 / 视频号 / 小红书 / B站。

如果信息不足，优先做合理假设并继续创作。只有缺失信息会导致脚本不合规、误导用户或无法落地时，才追问。

### 2. 先抓住前三秒（按时长分档）

开场必须有视觉钩子或扎心台词，具体定义按总时长分档：

- 15s 以内脚本：前 2-3s 必须有钩子。
- 30s 脚本：前 3-5s 必须有钩子。
- 60s+ 脚本：前 5s 有钩子，并在 20-25s 处放一个"次钩子/反转"。

可以使用：

- 反常动作：比如把粉底滴在干橘子皮上，而不是直接说"很服帖"。
- 痛点特写：比如女生对着镜子扒拉眼袋，停两秒，叹一口气。
- 强对比：比如同一张脸，一半斑驳，一半干净。
- 生活冲突：比如会议前打开电脑，发现方案还停在空白页。

避免平淡开场：

- "今天给大家介绍一款产品。"
- "这是一款非常好用的东西。"
- "你知道吗？"

### 3. 把卖点翻译成动作

不要只复述卖点。每个重要卖点都要转成可拍摄场景。

使用公式：

`属性 -> 好处 -> 具体动作/场景演示`

示例：

- `含保湿成分 -> 不容易干卡 -> 下午三点，纸巾轻按鼻翼，纸上没有明显斑驳粉痕。`
- `轻量便携 -> 出门省空间 -> 女生把它塞进小包夹层，拉链顺手拉上。`
- `操作简单 -> 新手也能上手 -> 用户看一眼按钮，三步完成设置，手指没有来回犹豫。`

**不要直接翻译的卖点**：抽象品牌主张（"自由/独立"等）、纯情感型卖点（"妈妈的味道"等）、合规敏感点（功效/医疗/金融等）。这些应先用具体场景承载信息，再转化动作，或先过合规红线再写。

### 4. 控制时长和信息密度

每个镜头的信息量要和时长匹配。

- 1-2s：适合单个动作、表情、物品特写、花字强调。
- 3-5s：适合一句短台词加一个清晰动作。
- 6s 以上：需要有动作变化、表情变化、镜头运动或信息推进，不能只停留在一个静态画面。

避免：

- 15s 脚本塞进 30s 的信息量，导致台词太满、画面来不及看。
- 15s 只有一行内容，画面没有变化，撑不起观看时长。
- 一个镜头同时讲痛点、卖点、价格、场景和转化，信息拥挤。

如果用户给的卖点过多，要优先保留核心卖点，把次要信息放进花字、道具细节或结尾补充，不要硬塞进台词。

### 5. 画面必须具象

画面描述必须是镜头能拍到的客观内容。

正确写法：

- "她低头盯着手机账单，拇指悬在付款按钮上，眉头皱了一下。"
- "男生把咖啡放到桌角，屏幕上弹出第 5 个未读消息，他揉了揉眉心。"
- "特写：手指拂过布满青苔的旧砖缝，指尖沾了一点灰。"

错误写法：

- "展示她很焦虑。"
- "体现产品高级感。"
- "画面展现历史沉淀感。"
- "展示产品很好用。"

### 6. 保证演员和场景能执行

人物状态、动作和情绪要写到演员能理解、能表演。

优先写：

- 具体动作：低头、停顿、皱眉、把东西推远、重新拿起手机。
- 可控表情：愣一下、笑一下、叹气、抿嘴、眼神躲开。
- 清楚情绪：尴尬、松口气、烦躁、犹豫、被戳中。

谨慎写：

- 需要高难度哭戏、爆发戏、复杂群演调度的桥段。
- 需要特殊地点、复杂灯光、大量道具或高成本置景的桥段。
- 需要难以准备的服装、设备、场景许可或危险动作的桥段。

除非用户明确要求高制作规格，否则默认用日常可找到的道具和场景，如桌面、镜子、手机、包、杯子、通勤路、办公室、卧室、厨房、便利店门口。

### 7. 台词必须像人说话

台词要短、顺、能直接读出来。

优先使用：

- 短句。
- 停顿感。
- 生活化表达。
- 适度语气词，比如"你看""哎""其实""别急""真的"。

避免：

- 书面语和 AI 腔：如"赋能""助力""打造闭环""在这个数字化的时代""深度链接用户"。
- 廉价网络热词：如"救命啊""家人们谁懂啊""绝绝子""yyds"。除非用户明确要求这种人设。
- 油腻夸张词：如"震撼""炸裂""神仙"。需要表达惊讶时，用动作表现，比如"她愣了一下，手里的水杯差点碰倒"。

### 8. 音画必须同步

台词说痛点，画面就拍痛点。

台词说效果，画面就拍效果或对比。

台词说场景，画面就进入那个场景。

不要让画面和台词变成两层皮。

### 9. 结构和镜头组织要顺

整条视频要有清楚的信息推进，不能只是把镜头和台词拼在一起。

常用结构：

- 痛点/冲突 -> 转折/发现 -> 展示/验证 -> 结果/记忆点。
- 场景进入 -> 问题出现 -> 使用动作 -> 前后对比 -> 收束。
- 观点抛出 -> 生活例子 -> 反差证明 -> 态度落点。

镜头衔接要方便拍摄和剪辑：

- 可以遵循全景交代环境、中景展示动作、近景/特写强调细节的基本逻辑。
- 不要无意义地频繁跳切，除非是明确的快节奏风格。
- 前后镜头之间要有动作、视线、道具或台词上的连接。
- 同一场景内优先减少频繁换机位，避免增加拍摄成本。

### 10. 情绪要有起伏

脚本不只讲清楚信息，还要有情绪推进。

可以使用：

- 先痛点，再转折，再释放。
- 先压抑，再松一口气。
- 先误解，再发现。
- 先日常小崩溃，再给出解决动作。

画面、台词、字幕和音乐的情绪方向要一致。不要台词很克制，BGM 却过度煽情；也不要画面轻松，字幕却写得很沉重。

### 11. 口播型分镜也要有画面变化

如果用户要的是"带分镜的口播视频脚本"，仍然不能写成毫无波澜的纯口播。

要设计：

- 景别切换。
- 手部道具动作。
- 表情反应。
- 背景音效。
- 屏幕录制。
- 产品特写。
- 花字强调。
- 快切转场。

镜头粒度建议：每 3-8s 一个镜头，用景别切换（中景/近景/特写/产品）或手部动作打破静态；禁止整条视频只有一个"中景主播对着镜头说"的镜头。

## 飞书文档排版约束

将短视频分镜脚本写入、改写或整理到飞书文档/Lark Doc 时，默认以「简洁文字 + 标准分镜表」为主，避免为了"美化""结构化"而大量使用装饰性块级组件。

### 排版设计

- 标题层级统一使用 H1（脚本总名，如「XX 产品 30s 分镜脚本」）、H2（一级章节，如「开场抓力 / 创意点 / 分镜表 / 备注」）、H3（小节），不做更深层级标题嵌套。
- 分镜表是脚本的核心主体，保留标准「镜号 / 景别 / 时长 / 画面描述 / 台词 / 机位/音效/花字」六列格式。
- 表格之外的说明文字（创意概述、目标人群、BGM 提示、拍摄注意事项等）使用普通 Markdown 段落或条目清单表达。

### 排版约束

- 除非用户明确要求，严禁大篇幅使用高亮块、信息提示块、Callout、引用块、代码块、分栏、卡片、颜色底纹或任何装饰性块级组件。
- 分镜表仅用于逐镜头对照；「开场抓力 / 卖点 / 注意事项 / 自查清单」等文字说明，优先用普通段落或简短条目清单表达，不要表格化或高亮化。
- 同一脚本内不使用多种风格的表格或频繁换列；分镜表格式应与本 guide「输出格式」一节保持一致。
- 禁止为了"让结构看起来完整"而增设无意义的章节、图或高亮块；装饰性组件若不对执行或理解带来实际增益，应视为冗余并删除。

## 输出格式

最终答案必须输出标准 Markdown 分镜脚本表格。

可以在表格前加一句简短承接语，用来概括脚本切入点。不要展示需求分析、创作思路、评分标准、内部检查过程或思维链。

固定表格格式：

| 镜号 | 景别 | 时长 | 画面描述 | 台词 | 机位/音效/花字 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 01 | 特写 | 2s | 干橘子皮被放在桌面上，粉底膏被压出一小块，粉底液滴在橘皮纹理上慢慢晕开 | （无台词） | 机位: 俯拍固定 / 音效: "嗒"一声粉底膏压下 / BGM: 轻节奏电子乐起 / 花字: "油皮？干卡？" |
| 02 | 近景 | 3s | 女生对着洗手间镜子用拇指轻按鼻翼两侧，拿开后纸巾上没有明显斑驳粉痕 | "下午三点再看——真的没花" | 机位: 平视轻微推镜 / 音效: 轻轻摩擦声 / 花字: "持妆 8h 实测" |
| 03 | 中景 | 4s | 女生把粉底膏和一支遮瑕收进巴掌大的随身化妆包，拉链顺手拉上，对镜笑一下 | "出门不用扛大包装，这一支够了" | 机位: 固定 / 音效: 拉链"唰" / 花字: "轻量便携 / 一收就走" |

- 时长统一写作 `Ns`（如 `2s`、`3s`），不写"2 秒"或数字加单位汉字。
- "机位/音效/花字"列用 `机位: / 音效: / BGM: / 花字:` 结构化标签分隔，便于后期拆分。

## BGM 和音效

BGM 不是每条视频都必须有。

- 强口播分镜（小红书/视频号/口播知识类）：BGM 可降低存在感，重点放在人声节奏、停顿和花字。
- 强场景分镜（抖音剧情/种草/对比类）：可以用 BGM 烘托情绪，如紧张、治愈、松弛、反差。
- 关键动作可以加音效，如"咔哒""叮""嗒""啪"，但不要过度堆叠。
- 若用户未指定平台：默认用"口播优先、BGM 克制"策略。

## 飞书格式差量

- **分镜/镜头表格是核心产物形态，正当**：分镜脚本的六列表格（镜号 / 景别 / 时长 / 画面描述 / 台词 / 机位·音效·花字）是本类型的主产物，属于正当富 block，全局克制红线不适用于它——不要因为"少用表格"而把逐镜头对照拆成段落，那会破坏拍摄与剪辑的可执行性。
- **表格之外仍守克制**：创意概述、目标人群、BGM 提示、拍摄注意事项、自查清单等说明性文字，用普通段落或简短条目清单表达，不要表格化、不要高亮化、不要为"结构完整"增设无意义章节。
- **正当≠堆砌**：分镜表只保留一张、列式固定；装饰性块级组件（callout / 引用块 / 代码块 / 分栏 / 卡片 / 颜色底纹）若不对拍摄或理解带来实际增益，仍视为冗余，应删掉。

## 输出前自检

生成或优化分镜脚本时，必须持续满足以下底线；若与创意表达冲突，优先满足质量门禁。最终输出前也用同一份清单自校：

- 需求完整：用户指定卖点、关键情绪、重点内容和指定风格必须呈现，不能为了戏剧化偏离需求。
- 可拍可演：画面必须能被镜头拍到，演员动作和情绪要明确，道具、服装、场景默认容易准备。
- 时长匹配：每个镜头的信息量要和时长匹配，不能信息过载，也不能内容太少硬撑时长；总时长与用户要求一致。
- 开场有抓力：按时长分档必须在规定秒数内出现痛点/冲突/反差/悬念/视觉钩子；60s+ 脚本还需一个次钩子。
- 结构顺畅：镜头前后要有动作、视线、道具、场景或台词上的连接，方便拍摄和后期拼接。
- 台词自然：台词要短句、顺口、有交流感，避免书面语、朗读感、AI 味和空泛营销词。
- 情绪统一：画面、台词、配乐、字幕的情绪方向要一致，整条视频要有情绪推进。
- 音画同步：台词说的内容与画面展示的内容一致，不出现"说的是痛点，拍的是产品开箱"。
- 格式正确：输出为标准 Markdown 分镜表；时长写 `Ns`；"机位/音效/花字"用结构化标签分隔。
- 合规安全：不得使用绝对化广告词、无依据承诺、虚构背书或高风险夸大功效表达；检索信息仅作创意参考，不写入未经确认的数据。
